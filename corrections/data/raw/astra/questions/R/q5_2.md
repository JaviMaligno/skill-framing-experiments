Create a URL slug from an invoice title, assuming Python 3.12 and ASCII-only output.

**Approach:** Add a pure helper in `utils/slugs.py`: normalize accents, lowercase, replace punctuation and whitespace with hyphens, and handle empty titles.

```python
import re
import unicodedata


def invoice_slug(title: str) -> str:
    normalized = unicodedata.normalize("NFKD", title)
    ascii_title = normalized.encode("ascii", "ignore").decode("ascii")
    slug = re.sub(r"[^a-z0-9]+", "-", ascii_title.lower()).strip("-")
    return slug or "invoice"
```

**Verify:**

```python
assert invoice_slug("Invoice #1042 — Acme Ltd.") == "invoice-1042-acme-ltd"
assert invoice_slug("  Café Consulting  ") == "cafe-consulting"
assert invoice_slug("") == "invoice"
assert invoice_slug("!!!") == "invoice"
```

Slugs aren’t unique; include the invoice ID in the URL if uniqueness is required.
