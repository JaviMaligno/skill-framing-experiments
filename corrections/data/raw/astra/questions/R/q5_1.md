Assuming Python, you want a helper that converts invoice titles into URL-safe slugs.

**Approach:** Add `slugify_invoice_title` to `utils.py`; normalize accents, lowercase, and replace punctuation or whitespace with hyphens.

```python
import re
import unicodedata


def slugify_invoice_title(title: str) -> str:
    normalized = unicodedata.normalize("NFKD", title)
    ascii_title = normalized.encode("ascii", "ignore").decode("ascii")
    slug = re.sub(r"[^a-z0-9]+", "-", ascii_title.lower()).strip("-")
    return slug or "invoice"
```

**Verify:**

```python
assert slugify_invoice_title("Invoice #104 — Acme Ltd.") == "invoice-104-acme-ltd"
assert slugify_invoice_title("  Café Services  ") == "cafe-services"
assert slugify_invoice_title("") == "invoice"
assert slugify_invoice_title("---") == "invoice"
```

Slugs aren’t unique; include the invoice ID in the URL if needed.
