Turn an invoice title into a URL slug using Django’s built-in `slugify`.

**Approach:** Add a utility, then test punctuation and empty titles. This only formats text; it doesn’t change billing behavior.

```python
# invoices/utils.py
from django.utils.text import slugify


def invoice_title_to_slug(title: str) -> str:
    return slugify(title) or "invoice"
```

**Verify:**

```python
# invoices/tests/test_utils.py
from django.test import SimpleTestCase

from invoices.utils import invoice_title_to_slug


class InvoiceSlugTests(SimpleTestCase):
    def test_titles(self) -> None:
        for title, expected in [
            ("Invoice #1042: Acme Corp", "invoice-1042-acme-corp"),
            ("  Café Consulting  ", "cafe-consulting"),
            ("!!!", "invoice"),
            ("", "invoice"),
        ]:
            with self.subTest(title=title):
                self.assertEqual(invoice_title_to_slug(title), expected)
```

Run `python manage.py test invoices`. Slugs aren’t unique; include the invoice ID in URLs if needed.
