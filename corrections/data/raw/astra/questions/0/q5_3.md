Turn an invoice title into a lowercase, hyphen-separated URL slug.

**Approach:** Add a helper in `invoices/utils.py` using Django’s built-in `slugify`.

```python
from django.utils.text import slugify


def invoice_title_to_slug(title: str) -> str:
    return slugify(title)
```

**Verify:**
```python
assert invoice_title_to_slug("Invoice #123 — Acme Corp") == "invoice-123-acme-corp"
assert invoice_title_to_slug("  Café consulting  ") == "cafe-consulting"
assert invoice_title_to_slug("") == ""
```

Slugs aren’t guaranteed unique; include the invoice ID in URLs when needed.
