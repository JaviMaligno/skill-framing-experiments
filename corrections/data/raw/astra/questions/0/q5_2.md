Use Django’s `slugify` to turn an invoice title into a URL-safe slug.

**Change:** Add this helper to `utils.py`:

```python
from django.utils.text import slugify


def invoice_title_to_slug(title: str) -> str:
    return slugify(title) or "invoice"
```

**Verify:**

```python
assert invoice_title_to_slug("Invoice #1042 — Acme Ltd") == "invoice-1042-acme-ltd"
assert invoice_title_to_slug("  Monthly Services  ") == "monthly-services"
assert invoice_title_to_slug("") == "invoice"
assert invoice_title_to_slug("!!!") == "invoice"
```

Slugs aren’t unique; include the invoice ID in the URL if needed.
