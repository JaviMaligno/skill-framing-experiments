Turn an invoice title into a URL slug using Django’s built-in `slugify`.

**Approach:** Add this to `invoices/utils.py`. Assume ASCII slugs; use `"invoice"` when the title produces an empty slug.

```python
from django.utils.text import slugify


def invoice_title_to_slug(title: str) -> str:
    return slugify(title) or "invoice"
```

**Verify:**

```python
assert invoice_title_to_slug("Invoice #1042 — October 2026") == "invoice-1042-october-2026"
assert invoice_title_to_slug("  ACME Consulting  ") == "acme-consulting"
assert invoice_title_to_slug("!!!") == "invoice"
assert invoice_title_to_slug("") == "invoice"
```

Slugs aren’t unique. If used to identify invoices, include the invoice ID in the URL.
