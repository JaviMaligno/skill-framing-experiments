Turn an invoice title into a URL slug, assuming Python/Django.

**Approach:** use Django’s `slugify` in `invoices/utils.py`, with a fallback for empty results.

```python
from django.utils.text import slugify


def invoice_title_slug(title: str) -> str:
    return slugify(title) or "invoice"
```

**Verify:**
```python
assert invoice_title_slug("Invoice #1042 — ACME Ltd.") == "invoice-1042-acme-ltd"
assert invoice_title_slug("  Café Consulting  ") == "cafe-consulting"
assert invoice_title_slug("!!!") == "invoice"
assert invoice_title_slug("") == "invoice"
```

Slugs aren’t unique; include the invoice ID in the URL if needed.
