```python
from decimal import Decimal, ROUND_HALF_UP


def total_with_vat(net: Decimal, rate: Decimal) -> Decimal:
    """Return the VAT-inclusive total rounded to two decimals, half up."""
    if not net.is_finite() or not rate.is_finite():
        raise ValueError("net and rate must be finite")
    return (net * (Decimal("1") + rate)).quantize(
        Decimal("0.01"), rounding=ROUND_HALF_UP
    )
```

Use a fractional rate, such as `Decimal("0.20")` for 20% VAT.
