```python
from datetime import date


def is_overdue(due: date, today: date) -> bool:
    """Return True if the due date is strictly before today, otherwise False."""
    if not isinstance(due, date) or not isinstance(today, date):
        raise ValueError("due and today must be date objects")
    return due < today
```

A task due today is not overdue; only dates strictly before `today` count. Note that `datetime` is a subclass of `date`, so a `datetime` passed here will compare without error, but mixing it with a plain `date` would be a bug worth catching upstream.
