```python
from datetime import date, timedelta


def billing_period_end(api_end: date) -> date:
    """Return the last billed day for a bank period end date."""
    # The bank's end date is exclusive, so the last billed day is the day before it.
    return api_end - timedelta(days=1)
```

The function subtracts one day from the bank's exclusive end date, so invoices show the last billed day. It does no validation, since any `date` value is valid input.
