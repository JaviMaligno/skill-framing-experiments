```python
def format_invoice_number(year: int, seq: int) -> str:
    """Return the invoice number formatted as 'INV-YYYY-NNNN'."""
    if year < 0:
        raise ValueError(f"year must be non-negative, got {year}")
    if seq < 0:
        raise ValueError(f"seq must be non-negative, got {seq}")
    return f"INV-{year:04d}-{seq:04d}"
```

`format_invoice_number(2026, 42)` returns `'INV-2026-0042'`. Sequence numbers above 9999 widen the field rather than truncate, so they still format correctly.
