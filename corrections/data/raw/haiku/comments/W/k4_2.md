```python
from decimal import ROUND_HALF_UP, Decimal


def total_with_vat(net: Decimal, rate: Decimal) -> Decimal:
    """Return net plus VAT at the given rate, rounded to 2 decimal places half up."""
    if not net.is_finite() or not rate.is_finite():
        raise ValueError("net and rate must be finite")
    if net < 0 or rate < 0:
        raise ValueError("net and rate must not be negative")
    # rate is a fraction (0.21 for 21%), not a percentage.
    total = net * (Decimal(1) + rate)
    return total.quantize(Decimal("0.01"), rounding=ROUND_HALF_UP)
```

`rate` is a fraction, so pass `Decimal("0.21")` for 21%. Negative or non-finite inputs raise `ValueError`.
