```python
import time
from collections.abc import Callable, Iterable
from typing import TypeVar

T = TypeVar("T")

# The provider allows one request per rolling second. The extra 0.1 s covers clock jitter.
MIN_INTERVAL_S: float = 1.1


def send_all(reminders: Iterable[T], send: Callable[[T], object]) -> None:
    """Calls send on each reminder in order, spaced at least 1.1 s apart, and returns None."""
    if not callable(send):
        raise ValueError("send must be callable")
    first = True
    for reminder in reminders:
        if not first:
            time.sleep(MIN_INTERVAL_S)
        send(reminder)
        first = False
```

The wait runs after each send returns, so slow sends only lengthen the gap. If `send` raises, the exception propagates and the remaining reminders are not sent.
