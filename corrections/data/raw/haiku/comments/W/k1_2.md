```python
from datetime import date, timedelta


def billing_period_end(api_end: date) -> date:
    """Return the last billed day for an exclusive bank API period end."""
    if api_end == date.min:
        raise ValueError("api_end is too early to step back one day")
    return api_end - timedelta(days=1)
```

The function subtracts one day from the bank's exclusive end date, so invoices show the last billed day. It raises ValueError for `date.min` instead of letting `timedelta` overflow.
