```python
import time
from collections.abc import Callable, Iterable


def send_all[T](reminders: Iterable[T], send: Callable[[T], object]) -> None:
    """Returns None after calling send on each reminder in order."""
    if not callable(send):
        raise ValueError("send must be callable")
    # The provider drops extra requests without an error, so spacing has to be
    # enforced here. Sleep only between calls. 1.1 s rather than 1.0 s leaves
    # margin for timer jitter at the window edge.
    for i, reminder in enumerate(reminders):
        if i:
            time.sleep(1.1)
        send(reminder)
```

The spacing is measured from the start of one call to the start of the next, so a slow `send` only adds to the gap. If `send` raises, the exception propagates and the remaining reminders are not sent.
