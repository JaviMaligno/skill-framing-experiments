```python
from datetime import date, timedelta


def billing_period_end(api_end: date) -> date:
    """Return the last billed day for a bank period end reported as exclusive."""
    if not isinstance(api_end, date):
        raise ValueError(f"api_end must be a date, got {type(api_end).__name__}")
    if api_end == date.min:
        raise ValueError("api_end has no preceding day")
    # The bank's end date is the first day NOT billed, so the last billed day is one day earlier.
    return api_end - timedelta(days=1)
```

The function subtracts one day from the bank's exclusive end date, so an end of 2026-10-31 returns 2026-10-30. Because `datetime` is a subclass of `date`, a `datetime` argument passes the type check and returns a `date`, so callers should pass plain dates.
