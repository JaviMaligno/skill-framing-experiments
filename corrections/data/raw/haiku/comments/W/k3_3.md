```python
from collections.abc import Iterable


def dedupe_payments(payments: Iterable[dict[str, object]]) -> list[dict[str, object]]:
    """Return one payment per ref, keeping the record with the lowest id."""
    canonical: dict[object, dict[str, object]] = {}
    for payment in payments:
        if not isinstance(payment, dict) or "id" not in payment or "ref" not in payment:
            raise ValueError("each payment must be a dict with 'id' and 'ref'")
        ref = payment["ref"]
        current = canonical.get(ref)
        # Duplicates arrive out of order, so the first record seen for a ref isn't necessarily canonical.
        if current is None or payment["id"] < current["id"]:
            canonical[ref] = payment
    return list(canonical.values())
```

Refs keep the order in which they first appeared, and each replacement keeps that position. Ids must be mutually comparable, or the comparison raises `TypeError`.
