```python
from decimal import Decimal, ROUND_HALF_UP


def total_with_vat(net: Decimal, rate: Decimal) -> Decimal:
    """Return net plus VAT at rate (e.g. 0.21 for 21%), rounded to 2 decimals half up."""
    if not net.is_finite() or not rate.is_finite():
        raise ValueError("net and rate must be finite")
    if net < 0 or rate < 0:
        raise ValueError("net and rate must be non-negative")
    total = net + net * rate
    return total.quantize(Decimal("0.01"), rounding=ROUND_HALF_UP)
```

`rate` is a fraction, so pass `Decimal("0.21")` for 21%, not `21`. Negative or non-finite inputs raise `ValueError`.
