```python
from datetime import date, datetime


def is_overdue(due: date, today: date) -> bool:
    """Return True if `today` is strictly after `due`; a task due today is not overdue."""
    # datetime is a subclass of date, so it would pass isinstance checks and
    # compare against a date with a TypeError. Reject it explicitly.
    for name, value in (("due", due), ("today", today)):
        if not isinstance(value, date) or isinstance(value, datetime):
            raise ValueError(f"{name} must be a date, not {type(value).__name__}")
    return today > due
```

Due today counts as not overdue, so the check is strictly greater than. I rejected `datetime` values because they would otherwise pass as dates and give misleading results.
