```python
from decimal import ROUND_HALF_UP, Decimal


def total_with_vat(net: Decimal, rate: Decimal) -> Decimal:
    """Return the gross amount (net plus VAT) rounded half up to 2 decimal places."""
    if not net.is_finite() or net < 0:
        raise ValueError(f"net must be a finite non-negative Decimal, got {net}")
    # rate is a fraction (0.21 for 21%), not a percentage.
    if not rate.is_finite() or rate < 0:
        raise ValueError(f"rate must be a finite non-negative fraction, got {rate}")
    # Round once at the end. Rounding the VAT amount separately can differ by a cent.
    gross = net * (Decimal(1) + rate)
    return gross.quantize(Decimal("0.01"), rounding=ROUND_HALF_UP)
```

I read `rate` as a fraction, so 21% is `Decimal("0.21")`; if your callers pass percentages, the function needs a `/ 100` first.
