```python
from datetime import date, datetime


def is_overdue(due: date, today: date) -> bool:
    """Return True if the due date is strictly before today, otherwise False."""
    for name, value in (("due", due), ("today", today)):
        # datetime subclasses date, and comparing it with a plain date raises TypeError, so reject it here.
        if not isinstance(value, date) or isinstance(value, datetime):
            raise ValueError(f"{name} must be a date, not {type(value).__name__}")
    return due < today
```

A due date equal to today is not overdue, so the item stays current until the day after it's due. Passing a `datetime` raises `ValueError`, so convert it with `.date()` first.
