```python
def format_invoice_number(year: int, seq: int) -> str:
    """Return the invoice number in the form INV-YYYY-NNNN."""
    if year < 0:
        raise ValueError("year must be non-negative")
    if seq < 0:
        raise ValueError("seq must be non-negative")
    return f"INV-{year:04d}-{seq:04d}"
```

This zero-pads both parts to four digits, so `format_invoice_number(2026, 42)` returns `'INV-2026-0042'`. A sequence above 9999 gets wider rather than being truncated.
