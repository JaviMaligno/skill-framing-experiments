```python
from decimal import ROUND_HALF_UP, Decimal


def total_with_vat(net: Decimal, rate: Decimal) -> Decimal:
    """Return net plus VAT, where rate is a fraction (0.20 for 20%), rounded to 2 decimals half up."""
    if not net.is_finite() or not rate.is_finite():
        raise ValueError("net and rate must be finite")
    if net < 0 or rate < 0:
        raise ValueError("net and rate must be non-negative")
    return (net * (1 + rate)).quantize(Decimal("0.01"), rounding=ROUND_HALF_UP)
```

The rate is expected as a fraction, so pass `Decimal("0.20")` rather than `Decimal("20")`. Negative or non-finite inputs raise `ValueError`.
