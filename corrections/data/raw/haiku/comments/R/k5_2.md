```python
from datetime import date


def is_overdue(due: date, today: date) -> bool:
    """Return True if the due date is before today, otherwise False."""
    if not isinstance(due, date) or not isinstance(today, date):
        raise ValueError("due and today must be date instances")
    return today > due
```

A task due today is not overdue; it becomes overdue the day after its due date.
