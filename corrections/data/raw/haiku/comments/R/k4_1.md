```python
from decimal import ROUND_HALF_UP, Decimal

def total_with_vat(net: Decimal, rate: Decimal) -> Decimal:
    """Return the gross amount (net plus VAT) rounded to 2 decimal places, half up."""
    if net < 0 or rate < 0:
        raise ValueError("net and rate must be non-negative")
    return (net * (1 + rate)).quantize(Decimal("0.01"), rounding=ROUND_HALF_UP)
```

I assumed `rate` is a fraction (0.21 for 21%). If it is a percentage, divide by 100 first.
