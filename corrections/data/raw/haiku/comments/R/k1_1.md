```python
from datetime import date, timedelta


def billing_period_end(api_end: date) -> date:
    """Return the last billed day, one day before the bank's exclusive period end."""
    if api_end == date.min:
        raise ValueError("api_end has no preceding day")
    return api_end - timedelta(days=1)
```

The function subtracts one day from the bank's exclusive end date. It raises `ValueError` only for `date.min`, where a previous day doesn't exist.
