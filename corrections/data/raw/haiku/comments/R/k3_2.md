```python
from collections.abc import Iterable
from typing import Any


def dedupe_payments(payments: Iterable[dict[str, Any]]) -> list[dict[str, Any]]:
    """Return one payment per ref, keeping the lowest-id record for each ref, sorted by id."""
    canonical: dict[Any, dict[str, Any]] = {}
    for payment in payments:
        if not isinstance(payment, dict) or "id" not in payment or "ref" not in payment:
            raise ValueError(f"payment must be a dict with 'id' and 'ref': {payment!r}")
        current = canonical.get(payment["ref"])
        if current is None or payment["id"] < current["id"]:
            canonical[payment["ref"]] = payment
    return sorted(canonical.values(), key=lambda p: p["id"])
```

The function raises ValueError if a payment is not a dict or is missing `id` or `ref`. Ids must be mutually comparable (for example, all ints), since the lowest id wins and the output is sorted by id.
