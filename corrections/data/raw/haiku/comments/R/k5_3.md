```python
from datetime import date, datetime


def is_overdue(due: date, today: date) -> bool:
    """Return True if the due date is before today, so a task due today is not overdue."""
    if not isinstance(due, date) or not isinstance(today, date):
        raise ValueError("due and today must be date objects")
    if isinstance(due, datetime) or isinstance(today, datetime):
        raise ValueError("due and today must be date objects, not datetime")
    return due < today
```

The function returns `due < today`, so a task due today is not overdue. It raises `ValueError` for non-date inputs and for `datetime` values, which would otherwise fail or compare incorrectly against plain dates.
