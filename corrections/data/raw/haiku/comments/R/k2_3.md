```python
import time
from collections.abc import Callable, Iterable
from typing import TypeVar

T = TypeVar("T")

# The provider silently drops requests that arrive within one rolling second of the previous one.
MIN_INTERVAL_SECONDS = 1.1


def send_all(reminders: Iterable[T], send: Callable[[T], object]) -> None:
    """Calls send for each reminder in order and returns None once all are sent."""
    last_start: float | None = None
    for reminder in reminders:
        if last_start is not None:
            remaining = MIN_INTERVAL_SECONDS - (time.monotonic() - last_start)
            if remaining > 0:
                time.sleep(remaining)
        last_start = time.monotonic()
        send(reminder)
```

The spacing is measured from the start of one send to the start of the next, so a slow `send` doesn't add extra delay. I didn't add input validation because Python already raises `TypeError` for a non-callable `send`.
