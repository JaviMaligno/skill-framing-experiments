```python
import time
from collections.abc import Callable, Iterable

MIN_INTERVAL_SECONDS = 1.1


def send_all[T](reminders: Iterable[T], send: Callable[[T], object]) -> None:
    """Call send once per reminder, in order, with at least 1.1 s between calls."""
    for index, reminder in enumerate(reminders):
        if index:
            # The provider silently drops requests that arrive within a rolling 1 s window.
            time.sleep(MIN_INTERVAL_SECONDS)
        send(reminder)
```

The sleep runs only between calls, so there is no delay before the first send or after the last. If `send` itself takes time, the gap after it returns still keeps consecutive calls at least 1.1 s apart.
