```python
def format_invoice_number(year: int, seq: int) -> str:
    """Return the invoice number for a year and sequence, e.g. 'INV-2026-0042'."""
    if year < 1:
        raise ValueError(f"year must be positive, got {year}")
    if not 1 <= seq <= 9999:
        # The invoice format allows four digits for the sequence.
        raise ValueError(f"seq must be between 1 and 9999, got {seq}")
    return f"INV-{year:04d}-{seq:04d}"
```

The function zero-pads the sequence to four digits and raises `ValueError` for a non-positive year or a sequence outside 1 to 9999. I chose the 1 to 9999 range because the four-digit format can't represent larger values.
