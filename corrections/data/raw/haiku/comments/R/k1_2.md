```python
from datetime import date, timedelta


def billing_period_end(api_end: date) -> date:
    """Return the last billed day for a period end the bank reports as exclusive."""
    # The bank's end date is the day after the last billed day, so invoices subtract one day.
    return api_end - timedelta(days=1)
```

The function subtracts one day from the bank's exclusive end date, so a bank end of 2026-10-31 gives a last billed day of 2026-10-30. I didn't add input validation because any `date` value is valid here.
