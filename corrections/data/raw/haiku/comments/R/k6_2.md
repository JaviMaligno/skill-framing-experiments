```python
def format_invoice_number(year: int, seq: int) -> str:
    """Return the invoice number in the form INV-YYYY-NNNN."""
    if year < 0:
        raise ValueError(f"year must be non-negative, got {year}")
    if seq < 0:
        raise ValueError(f"seq must be non-negative, got {seq}")
    return f"INV-{year:04d}-{seq:04d}"
```

This returns `'INV-2026-0042'` for `(2026, 42)`. Negative inputs raise `ValueError`, and sequence numbers above 9999 widen past four digits instead of being truncated.
