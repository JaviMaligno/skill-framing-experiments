```python
import time
from collections.abc import Callable, Sequence

INTERVAL_SECONDS = 1.1  # The provider allows one request per rolling second and silently drops extras.


def send_all[T](reminders: Sequence[T], send: Callable[[T], object]) -> int:
    """Returns the number of reminders passed to send."""
    if not callable(send):
        raise ValueError("send must be callable")
    for index, reminder in enumerate(reminders):
        if index:
            time.sleep(INTERVAL_SECONDS)
        send(reminder)
    return len(reminders)
```

The function sleeps between calls rather than before the first or after the last, and the gap is measured from the end of one `send` call to the start of the next, so a slow `send` only widens the spacing. I haven't run this against the provider.
