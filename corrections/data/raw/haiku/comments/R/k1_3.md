```python
from datetime import date, timedelta


def billing_period_end(api_end: date) -> date:
    """Return the last billed day, one day before the bank's exclusive end date."""
    if api_end == date.min:
        raise ValueError("api_end has no preceding day")
    # The bank reports the exclusive end (the day after the last billed day).
    return api_end - timedelta(days=1)
```

The function subtracts one day from the bank's exclusive end date to get the last billed day for invoices. It raises ValueError only for `date.min`, where subtracting a day would overflow.
