```python
from collections.abc import Iterable
from typing import Any


def dedupe_payments(payments: Iterable[dict[str, Any]]) -> list[dict[str, Any]]:
    """Return one payment per ref, keeping the record with the lowest id for each ref."""
    canonical: dict[Any, dict[str, Any]] = {}
    for payment in payments:
        ref = payment["ref"]
        current = canonical.get(ref)
        if current is None or payment["id"] < current["id"]:
            canonical[ref] = payment
    return list(canonical.values())
```

The function keeps a single pass over the input and does not depend on arrival order, so out-of-order duplicates resolve to the lowest id. Output order follows the first appearance of each ref, and a record missing `id` or `ref` raises `KeyError`.
