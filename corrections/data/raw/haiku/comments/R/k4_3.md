```python
from decimal import ROUND_HALF_UP, Decimal


def total_with_vat(net: Decimal, rate: Decimal) -> Decimal:
    """Return the gross amount (net plus VAT) rounded to 2 decimal places, half up."""
    if not net.is_finite() or not rate.is_finite():
        raise ValueError("net and rate must be finite")
    if rate < 0:
        raise ValueError("rate must not be negative")
    gross = net * (1 + rate)
    return gross.quantize(Decimal("0.01"), rounding=ROUND_HALF_UP)
```

The rate is a fraction, so pass `Decimal("0.21")` for 21% VAT. Passing `Decimal` values throughout avoids float rounding errors.
