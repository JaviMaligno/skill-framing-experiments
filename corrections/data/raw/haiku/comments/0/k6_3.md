```python
def format_invoice_number(year: int, seq: int) -> str:
    """Return the invoice number formatted as 'INV-YYYY-NNNN'."""
    if isinstance(year, bool) or not isinstance(year, int) or year < 0:
        raise ValueError(f"year must be a non-negative int, got {year!r}")
    if isinstance(seq, bool) or not isinstance(seq, int) or seq < 0:
        raise ValueError(f"seq must be a non-negative int, got {seq!r}")
    return f"INV-{year:04d}-{seq:04d}"
```

This zero-pads the year and sequence to four digits each, so `format_invoice_number(2026, 42)` returns `'INV-2026-0042'`. Negative or non-integer inputs raise `ValueError`.
