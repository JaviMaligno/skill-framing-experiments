```python
def format_invoice_number(year: int, seq: int) -> str:
    """Return the invoice number in the form INV-YYYY-NNNN."""
    if not isinstance(year, int) or isinstance(year, bool) or year < 0:
        raise ValueError(f"year must be a non-negative integer, got {year!r}")
    if not isinstance(seq, int) or isinstance(seq, bool) or seq < 0:
        raise ValueError(f"seq must be a non-negative integer, got {seq!r}")
    return f"INV-{year:04d}-{seq:04d}"
```

This returns `format_invoice_number(2026, 42)` as `'INV-2026-0042'`. It raises `ValueError` for negative or non-integer inputs, and numbers wider than four digits print in full rather than being truncated.
