```python
from datetime import date, timedelta


def billing_period_end(api_end: date) -> date:
    """Return the last billed day, which is the bank's exclusive end date minus one day."""
    if not isinstance(api_end, date):
        raise ValueError("api_end must be a date")
    return api_end - timedelta(days=1)
```

The bank's exclusive end date is shifted back one day so invoices show the last billed day. Non-date input raises `ValueError`, per the billing service conventions.
