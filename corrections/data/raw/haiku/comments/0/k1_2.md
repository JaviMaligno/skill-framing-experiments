```python
from datetime import date, timedelta

def billing_period_end(api_end: date) -> date:
    """Return the last billed day, one day before the bank's exclusive end date."""
    if api_end == date.min:
        raise ValueError("api_end has no preceding day")
    return api_end - timedelta(days=1)
```

The bank's exclusive end date minus one day gives the last billed day that invoices should show. The guard raises `ValueError` for `date.min`, the only input with no preceding day.
