```python
from datetime import date, datetime


def is_overdue(due: date, today: date) -> bool:
    """Return True if the due date is before today, otherwise False."""
    if isinstance(due, datetime) or isinstance(today, datetime):
        raise ValueError("due and today must be date objects, not datetime")
    return today > due
```

A task due today is not overdue; it becomes overdue the day after its due date. Passing a `datetime` raises `ValueError` because comparing it with a `date` would otherwise give a confusing result.
