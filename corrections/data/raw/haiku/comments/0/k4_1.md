```python
from decimal import ROUND_HALF_UP, Decimal


def total_with_vat(net: Decimal, rate: Decimal) -> Decimal:
    """Return net plus VAT at the given rate, rounded to 2 decimals half up."""
    if not net.is_finite() or net < 0:
        raise ValueError("net must be a finite, non-negative amount")
    if not rate.is_finite() or rate < 0:
        raise ValueError("rate must be a finite, non-negative fraction such as Decimal('0.21')")
    total = net * (Decimal(1) + rate)
    return total.quantize(Decimal("0.01"), rounding=ROUND_HALF_UP)
```

The `rate` is a fraction, so pass `Decimal("0.21")` for 21% VAT. I assumed negative amounts and rates are invalid, so the function raises `ValueError` for them.
