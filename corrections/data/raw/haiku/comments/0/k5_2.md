```python
from datetime import date


def is_overdue(due: date, today: date) -> bool:
    """Return True if the due date is before today, otherwise False."""
    if not isinstance(due, date) or not isinstance(today, date):
        raise ValueError("due and today must be date objects")
    return due < today
```

A task due today is not overdue; only dates strictly before `today` count. Non-`date` inputs raise `ValueError`, and `datetime` values are rejected too because `datetime` is a subclass of `date` and mixing the two in comparisons would be a bug.
