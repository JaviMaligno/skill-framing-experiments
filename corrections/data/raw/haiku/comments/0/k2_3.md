```python
import time
from collections.abc import Callable, Iterable
from typing import Any


def send_all(reminders: Iterable[Any], send: Callable[[Any], Any]) -> None:
    """Call send(r) for each reminder, sleeping 1.1 seconds between calls so the provider's one-per-second limit is respected."""
    first = True
    for r in reminders:
        if not first:
            time.sleep(1.1)
        first = False
        send(r)
```

This waits between sends rather than after the last one, so it doesn't add an unnecessary delay at the end. Timing uses `time.sleep`, which is not affected by wall-clock changes.
