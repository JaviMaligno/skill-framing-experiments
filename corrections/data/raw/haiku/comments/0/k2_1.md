```python
import time
from collections.abc import Callable, Sequence
from typing import TypeVar

R = TypeVar("R")

MIN_INTERVAL_S = 1.1


def send_all(reminders: Sequence[R], send: Callable[[R], object]) -> int:
    """Calls send on each reminder, at least 1.1 s apart, and returns how many were sent."""
    if not callable(send):
        raise ValueError("send must be callable")

    sent = 0
    for reminder in reminders:
        if sent > 0:
            time.sleep(MIN_INTERVAL_S)
        send(reminder)
        sent += 1
    return sent
```

The sleep runs before every call except the first, so the provider never sees two calls closer than 1.1 s. A non-callable `send` raises `ValueError`.
