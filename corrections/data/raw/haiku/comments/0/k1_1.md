```python
from datetime import date, timedelta


def billing_period_end(api_end: date) -> date:
    """Return the last billed day, given the bank's exclusive period end date."""
    if api_end == date.min:
        raise ValueError("api_end is too early to have a previous day")
    return api_end - timedelta(days=1)
```

The bank's end date is exclusive, so the last billed day is one day earlier. The function subtracts one day and raises ValueError for `date.min`, where that subtraction would overflow.
