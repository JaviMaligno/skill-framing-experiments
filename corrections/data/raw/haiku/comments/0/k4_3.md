```python
from decimal import Decimal, ROUND_HALF_UP


def total_with_vat(net: Decimal, rate: Decimal) -> Decimal:
    """Return the gross total (net plus VAT) rounded to 2 decimal places, half up."""
    if net < 0:
        raise ValueError("net must be non-negative")
    if rate < 0:
        raise ValueError("rate must be non-negative")
    gross = net * (Decimal(1) + rate)
    return gross.quantize(Decimal("0.01"), rounding=ROUND_HALF_UP)
```

The rate is a fraction (for example, `Decimal("0.20")` for 20% VAT). Negative inputs raise `ValueError`.
