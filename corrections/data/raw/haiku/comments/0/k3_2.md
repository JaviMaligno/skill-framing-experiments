```python
from collections.abc import Iterable


def dedupe_payments(payments: Iterable[dict]) -> list[dict]:
    """Return one payment per 'ref', keeping the record with the lowest 'id'."""
    canonical: dict = {}
    for payment in payments:
        ref = payment["ref"]
        if ref not in canonical or payment["id"] < canonical[ref]["id"]:
            canonical[ref] = payment
    return list(canonical.values())
```

This keeps the first-seen position of each ref and replaces it whenever a lower `id` arrives, so out-of-order duplicates are handled regardless of input order. It assumes `id` values are mutually comparable (for example, all ints).
