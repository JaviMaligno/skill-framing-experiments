```python
import time
from collections.abc import Callable, Iterable
from typing import Any

MIN_INTERVAL_S: float = 1.1


def send_all(reminders: Iterable[Any], send: Callable[[Any], object]) -> None:
    """Call send on each reminder in order, pausing 1.1 s between calls; returns None."""
    if not callable(send):
        raise ValueError("send must be callable")
    for index, reminder in enumerate(reminders):
        if index:
            time.sleep(MIN_INTERVAL_S)
        send(reminder)
```

The pause runs between calls, not before the first one, so a single reminder is sent immediately. Consecutive calls are always at least 1.1 s apart, which stays within the provider's one-per-rolling-second limit.
