**2. Decide where the conversion happens**

I'll assume the database keeps integer cents and only the public API boundary changes. That avoids a migration, which keeps the change small and reversible. Converting the stored column to `Decimal` euros is a separate step that needs a reviewed migration.

```python
from decimal import ROUND_HALF_UP, Decimal

CENTS_PER_EUR: Decimal = Decimal(100)
EUR_QUANTUM: Decimal = Decimal("0.01")


def cents_to_euros(cents: int) -> Decimal:
    return (Decimal(cents) / CENTS_PER_EUR).quantize(EUR_QUANTUM, rounding=ROUND_HALF_UP)


def euros_to_cents(euros: Decimal | str) -> int:
    return int((Decimal(euros) * CENTS_PER_EUR).quantize(Decimal("1"), rounding=ROUND_HALF_UP))
```
