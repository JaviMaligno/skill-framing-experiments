You want a function that converts an invoice title like `Invoice #2026/014 – Café Déjà Vu` into a URL-safe slug like `invoice-2026-014-cafe-deja-vu`.

**Approach**
1. Strip accents by decomposing Unicode (NFKD) and dropping non-ASCII bytes, so `é` becomes `e`.
2. Lowercase, replace each run of non-alphanumeric characters with a single hyphen, and trim hyphens from the ends.
3. Truncate to a maximum length without leaving a trailing hyphen.

This is a single pure function with no dependencies, so it can live in a shared utilities module such as `billing/utils/slugs.py` and be tested without Django.

**Code** (Python 3.12, standard library only)

```python
import re
import unicodedata

_NON_ALNUM: re.Pattern[str] = re.compile(r"[^a-z0-9]+")


def invoice_slug(title: str, max_length: int = 80) -> str:
    """Convert an invoice title into a URL-safe slug.

    Returns an empty string if the title has no ASCII letters or digits;
    callers should supply a fallback (for example, the invoice ID).
    """
    ascii_text: str = (
        unicodedata.normalize("NFKD", title)
        .encode("ascii", "ignore")
        .decode("ascii")
    )
    slug: str = _NON_ALNUM.sub("-", ascii_text.lower()).strip("-")
    if max_length > 0 and len(slug) > max_length:
        slug = slug[:max_length].rstrip("-")
    return slug
```

**Tests** (`tests/test_invoice_slug.py`)

```python
import pytest

from billing.utils.slugs import invoice_slug


@pytest.mark.parametrize(
    ("title", "expected"),
    [
        ("Invoice #2026/014 – Café Déjà Vu", "invoice-2026-014-cafe-deja-vu"),
        ("  Acme   Corp  ", "acme-corp"),
        ("Q3 -- Services & Support!!", "q3-services-support"),
        ("!!!", ""),
        ("", ""),
    ],
)
def test_invoice_slug(title: str, expected: str) -> None:
    assert invoice_slug(title) == expected


def test_truncation_has_no_trailing_hyphen() -> None:
    slug = invoice_slug("aaaa bbbb cccc", max_length=5)
    assert slug == "aaaa"
    assert not slug.endswith("-")
```

**Verify**
- Run `python -m pytest tests/test_invoice_slug.py -v`. All cases should pass.
- Run `mypy billing/utils/slugs.py` to confirm the type hints.

**Assumptions I made**
- Slugs are lowercase ASCII with hyphens, and the default max length is 80. Change `max_length` if your URLs have a different limit.
- Characters with no Unicode decomposition are dropped. For example, `Straße` becomes `strae`, not `strasse`. If German titles matter, add a replacement map (such as `ß` → `ss`) before the NFKD step.
- Titles can collide, such as two invoices both titled "Monthly retainer". If slugs must be unique, append the invoice ID or a counter at the call site. I didn't add that here because it needs a database check.
