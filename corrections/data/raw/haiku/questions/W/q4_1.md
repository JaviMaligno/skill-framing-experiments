**Approach**
1. Add a `CopyLinkButton` component that copies the current page URL with `navigator.clipboard`, with a fallback for when clipboard access is blocked.
2. Place it beside the invoice number in the detail page header.
3. Verify it manually.

**1. New component** (e.g. `src/components/CopyLinkButton.tsx`)

```tsx
import { useEffect, useState } from "react";

type Props = {
  url?: string; // defaults to the current page URL
  className?: string;
};

export function CopyLinkButton({ url, className }: Props) {
  const [copied, setCopied] = useState(false);

  useEffect(() => {
    if (!copied) return;
    const timer = window.setTimeout(() => setCopied(false), 2000);
    return () => window.clearTimeout(timer);
  }, [copied]);

  async function handleCopy() {
    const link = url ?? window.location.href;
    try {
      await navigator.clipboard.writeText(link);
      setCopied(true);
    } catch {
      // Clipboard API unavailable (insecure context or permission denied)
      window.prompt("Copy this link:", link);
    }
  }

  return (
    <button
      type="button"
      onClick={handleCopy}
      className={className}
      aria-live="polite"
    >
      {copied ? "Copied!" : "Copy link"}
    </button>
  );
}
```

**2. Use it on the invoice detail page** (next to the invoice number)

```tsx
import { CopyLinkButton } from "@/components/CopyLinkButton";

// ...inside the header
<div className="flex items-center gap-2">
  <h1 className="text-xl font-semibold">Invoice #{invoice.number}</h1>
  <CopyLinkButton className="text-sm text-blue-600 hover:underline" />
</div>
```

Adjust the import path and the classes to match your codebase. If the header already uses a flex container, put the button inside it instead of wrapping it again.

**Assumptions**
- The page's URL is the canonical link to the invoice. If you want a different link (for example, a shareable URL with a token), pass it as `url={...}`.
- If invoices sit behind login, the copied link only works for users who can sign in. That's the existing access rule, so nothing changes, but recipients will need access.
- No backend change is needed.

**Verify**

- The label switches to "Copied!" for about 2 seconds, then reverts.
- Over plain HTTP or with clipboard permission denied, the fallback prompt should show the link.
