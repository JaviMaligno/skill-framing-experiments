**Request:** Paginate `/reports` so it returns one page of reports at a time instead of all of them.

**Assumptions:**
- The page is a Django class-based or function view rendering a template. Your stack is Django 5, so this is the likely case.
- The model is `Report` with a `created_at` field. Adjust names as needed.
- Page size is 25, with `?page=N` in the URL.

**Approach:**
1. Paginate the queryset in the view, not in the template, so the database fetches only the current page.
2. Order by a stable key so pages don't shift between requests.
3. Use `select_related` on foreign keys the template reads, to avoid N+1 queries.
4. Render prev/next controls in the template.

**1. `reports/views.py`**

```python
from django.core.paginator import Paginator, EmptyPage, PageNotAnInteger
from django.shortcuts import render

from .models import Report

PAGE_SIZE = 25


def report_list(request):
    qs = (
        Report.objects
        .select_related("owner")  # adjust to FKs the template uses
        .order_by("-created_at", "-pk")  # stable ordering across pages
    )

    paginator = Paginator(qs, PAGE_SIZE)
    try:
        page = paginator.page(request.GET.get("page", 1))
    except PageNotAnInteger:
        page = paginator.page(1)
    except EmptyPage:
        page = paginator.page(paginator.num_pages)

    return render(request, "reports/report_list.html", {
        "page_obj": page,
        "reports": page.object_list,
    })
```

If `/reports` is a class-based `ListView`, set `paginate_by = 25` and `ordering = ["-created_at", "-pk"]` and remove the function body.
