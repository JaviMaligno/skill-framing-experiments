I'll write a Python 3.12 function that converts an invoice title to a lowercase, ASCII-only, hyphen-separated slug with a length cap and a fallback for titles with no usable characters. I can't write files into your repo from this session, so save the code below yourself, for example as `invoices/slugs.py`.

**Approach**
1. `invoices/slugs.py`: the `invoice_slug` function.
2. `tests/test_invoice_slugs.py`: pytest cases for the edge cases.

**`invoices/slugs.py`**

```python
from __future__ import annotations

import re
import unicodedata

_NON_ALNUM: re.Pattern[str] = re.compile(r"[^a-z0-9]+")


def invoice_slug(title: str, *, max_length: int = 80, fallback: str = "invoice") -> str:
    """Turn an invoice title into a URL-safe slug.

    >>> invoice_slug("Invoice #1042 — Café Müller / Q3 2026")
    'invoice-1042-cafe-muller-q3-2026'
    """
    # Decompose accented characters, then drop anything non-ASCII ("é" -> "e").
    ascii_text = (
        unicodedata.normalize("NFKD", title)
        .encode("ascii", "ignore")
        .decode("ascii")
    )
    slug = _NON_ALNUM.sub("-", ascii_text.lower()).strip("-")
    if len(slug) > max_length:
        slug = slug[:max_length].rstrip("-")
    return slug or fallback
```

**`tests/test_invoice_slugs.py`**

```python
import pytest

from invoices.slugs import invoice_slug


@pytest.mark.parametrize(
    ("title", "expected"),
    [
        ("Invoice #1042 — Café Müller / Q3 2026", "invoice-1042-cafe-muller-q3-2026"),
        ("  --Acme, Inc.--  ", "acme-inc"),
        ("!!!", "invoice"),
        ("", "invoice"),
    ],
)
def test_invoice_slug(title: str, expected: str) -> None:
    assert invoice_slug(title) == expected


def test_truncation_does_not_leave_trailing_hyphen() -> None:
    assert invoice_slug("a " * 50, max_length=4) == "a-a"
```

**Known limitation:** characters with no ASCII decomposition are dropped, so "Straße" becomes "strae". If German or other non-Latin titles matter, add a transliteration step such as the `unidecode` package before the normalize call.
