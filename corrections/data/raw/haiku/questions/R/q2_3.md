I'm assuming a Django/DRF public API where `Product` stores `price_cents` as an integer and serializes it as `price`. I can't read or edit your repo from this session, so the names below are placeholders to confirm with the grep in step 1.

**Approach**

1. Find every use of cents: models, serializers, views, OpenAPI docs, React components, tests, fixtures, webhooks, and emails.
2. Add a `price_eur` decimal column, backfill it from `price_cents`, and keep the old column for rollback.
3. Point the public serializer at `price_eur`, so `price` is returned and accepted in euros.
4. Remove `/ 100` and `* 100` from the front end and any other consumers.
5. Drop `price_cents` in a later migration, after the change has been stable in production.

Because this changes the meaning of a public field, it breaks existing API clients. Either announce it and version the endpoint, or gate the serializer switch behind a flag.

```python
# catalog/migrations/0011_backfill_price_eur.py
from decimal import Decimal
from django.db import migrations

CENT = Decimal("0.01")

def forwards(apps, schema_editor):
    Product = apps.get_model("catalog", "Product")
    batch = []
    for p in Product.objects.filter(price_eur__isnull=True).iterator(chunk_size=1000):
        p.price_eur = (Decimal(p.price_cents) / 100).quantize(CENT)
        batch.append(p)
        if len(batch) >= 1000:
            Product.objects.bulk_update(batch, ["price_eur"])
            batch.clear()
    if batch:
        Product.objects.bulk_update(batch, ["price_eur"])

def backwards(apps, schema_editor):
    Product = apps.get_model("catalog", "Product")
    batch = []
    for p in Product.objects.filter(price_eur__isnull=False).iterator(chunk_size=1000):
        p.price_cents = int((p.price_eur * 100).to_integral_value())
        batch.append(p)
    Product.objects.bulk_update(batch, ["price_cents"], batch_size=1000)

class Migration(migrations.Migration):
    dependencies = [("catalog", "0010_product_price_eur")]
    operations = [migrations.RunPython(forwards, backwards)]
```

Keep the column nullable until the backfill is verified, then make it `null=False` in a later migration.

**4. Serializer**

```python
# catalog/serializers.py
from decimal import Decimal
from rest_framework import serializers
from .models import Product

class ProductSerializer(serializers.ModelSerializer):
    price = serializers.DecimalField(
        source="price_eur",
        max_digits=10,
        decimal_places=2,
        min_value=Decimal("0.00"),
        coerce_to_string=False,  # JSON number, e.g. 12.5, instead of "12.50"
    )

    class Meta:
        model = Product
        fields = ["id", "name", "price"]
```

If you prefer exact string output like `"12.50"`, set `coerce_to_string=True`, the DRF default. Pick one and document it, because clients parse the two differently.

If you need a rollout flag, switch between the two serializers in the view with `settings.PUBLIC_API_PRICE_IN_EUR`. Otherwise, ship it in the versioned endpoint.
