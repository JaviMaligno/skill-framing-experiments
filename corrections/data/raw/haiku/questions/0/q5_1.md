**Request:** A helper that converts an invoice title into a URL-safe slug.

**Approach:**
1. Put the function in `invoice_slug.py`, with no dependencies beyond the standard library.
2. Normalize Unicode and drop accents (`Café` becomes `cafe`), lowercase, collapse runs of non-alphanumerics into single hyphens, and trim hyphens from the ends.
3. Enforce a maximum length without leaving a trailing hyphen, and fall back to `invoice` when nothing usable remains.
4. Cover it with pytest.

**`invoice_slug.py`**

```python
from __future__ import annotations

import re
import unicodedata

_NON_ALNUM = re.compile(r"[^a-z0-9]+")


def invoice_slug(title: str, *, max_length: int = 80, fallback: str = "invoice") -> str:
    """Turn an invoice title into a URL-safe slug.

    >>> invoice_slug("Acme GmbH - Invoice #2026/001 (Café)")
    'acme-gmbh-invoice-2026-001-cafe'
    """
    ascii_text = (
        unicodedata.normalize("NFKD", title)
        .encode("ascii", "ignore")
        .decode("ascii")
    )
    slug = _NON_ALNUM.sub("-", ascii_text.lower()).strip("-")
    if len(slug) > max_length:
        slug = slug[:max_length].rstrip("-")
    return slug or fallback
```

**`test_invoice_slug.py`**

```python
import pytest

from invoice_slug import invoice_slug


@pytest.mark.parametrize(
    ("title", "expected"),
    [
        ("Invoice #2026/001", "invoice-2026-001"),
        ("  Acme   GmbH  ", "acme-gmbh"),
        ("Café Señor — Oct 2026", "cafe-senor-oct-2026"),
        ("INV-0042", "inv-0042"),
        ("!!!", "invoice"),
        ("", "invoice"),
    ],
)
def test_slug(title: str, expected: str) -> None:
    assert invoice_slug(title) == expected


def test_max_length_has_no_trailing_hyphen() -> None:
    slug = invoice_slug("a " * 50, max_length=5)
    assert slug == "a-a-a"
    assert len(slug) <= 5
```

**Notes:**
- Characters with no ASCII decomposition are dropped, so `ß` disappears (`Straße` becomes `strae`). If that matters for your customers, add an explicit mapping table before the NFKD step.
- If this is only for Django models, `django.utils.text.slugify` already does most of this. It doesn't truncate or apply a fallback, so you'd still need a thin wrapper for those.
