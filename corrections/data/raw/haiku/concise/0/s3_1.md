**Subject: WELCOME30 discount code leaked and disabled; new per-customer codes available**

The WELCOME30 discount code was posted on a coupon site and used by people who aren't customers. We disabled it at 10:00 today.

- **What happened:** The code was redeemed 214 times in 2 days, all by non-customers.
- **What we did:** We disabled WELCOME30 at 10:00 today. We also built a new generator that creates a separate code for each customer, using our existing promotions system.
- **Impact:** WELCOME30 no longer works. Any customer who needs a discount now needs a new per-customer code.

**Sales: stop offering WELCOME30 immediately.** To give a customer a discount, **generate their code in the admin under Promotions > Generate.**
