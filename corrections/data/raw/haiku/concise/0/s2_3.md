**CSV export date bug: fixed, and some exports need to be run again**

We found a bug in CSV exports for accounts in UTC+ time zones. The time zone offset was applied twice, so dates came out one day late. The exporter is fixed and a new test covers this case. We have not corrected exports that already exist, so the affected ones need to be re-run.

**Impact:** Exports created 6-17 October for customers outside the UK show dates one day late.

**Support:** Tell affected customers to run the export again.

**Finance:** Re-run your September close export before Monday.
