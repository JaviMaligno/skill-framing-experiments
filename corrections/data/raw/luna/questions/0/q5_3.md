**Request:** Add a helper that converts an invoice title into a URL slug.

**Approach:** I can’t modify files in this read-only workspace, but the helper should normalize the title, replace runs of non-alphanumeric characters with hyphens, and trim hyphens at both ends.

```python
import re
import unicodedata


def invoice_title_to_slug(title: str) -> str:
    """Convert an invoice title into a lowercase, hyphen-separated URL slug."""
    normalized = unicodedata.normalize("NFKD", title)
    ascii_title = normalized.encode("ascii", "ignore").decode("ascii")
    return re.sub(r"-+", "-", re.sub(r"[^a-z0-9]+", "-", ascii_title.lower())).strip("-")
```

**Verify:** `invoice_title_to_slug("Invoice #42 — May 2026")` returns `"invoice-42-may-2026"`; an empty or punctuation-only title returns `""`.
