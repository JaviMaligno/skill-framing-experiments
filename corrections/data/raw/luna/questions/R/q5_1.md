Understood: add a reusable R helper that converts an invoice title to a URL-friendly slug. I couldn’t inspect or edit the project because filesystem access is read-only, so here’s a dependency-free helper you can add:

```r
invoice_title_to_slug <- function(title) {
  stopifnot(is.character(title), length(title) == 1L, !is.na(title))

  slug <- iconv(title, from = "", to = "ASCII//TRANSLIT")
  if (is.na(slug)) slug <- title

  slug <- tolower(slug)
  slug <- gsub("[^a-z0-9]+", "-", slug)
  slug <- gsub("(^-|-$)", "", slug)

  slug
}
```

For example, `"Invoice #42: Café Supplies"` becomes `"invoice-42-cafe-supplies"`. You can verify it with:

```r
stopifnot(invoice_title_to_slug("Invoice #42: Café Supplies") ==
            "invoice-42-cafe-supplies")
```
