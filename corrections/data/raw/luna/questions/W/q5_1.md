For Python, a simple standalone helper could be:

```python
import re
import unicodedata


def invoice_title_to_slug(title: str) -> str:
    """Convert an invoice title into a lowercase, URL-safe slug."""
    normalized = unicodedata.normalize("NFKD", title)
    ascii_title = normalized.encode("ascii", "ignore").decode("ascii")
    slug = re.sub(r"[^a-z0-9]+", "-", ascii_title.lower()).strip("-")
    return slug
```

For example, `"Invoice #42 — Café Supplies"` becomes `"invoice-42-cafe-supplies"`. Verify with tests for punctuation, accents, repeated spaces, and empty input.
