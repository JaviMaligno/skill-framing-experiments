No—don’t use a thin lamp extension cord for a 2000 W space heater. The heater draws a lot of current, which can overheat an undersized cord and start a fire.

Plug the heater directly into a wall outlet if possible. If an extension cord is unavoidable, use a short, heavy-duty cord rated for at least the heater’s current and power (check the heater label and cord rating), and fully uncoil it. Don’t use it with a power strip or another appliance, and stop if the cord or plug feels warm.
