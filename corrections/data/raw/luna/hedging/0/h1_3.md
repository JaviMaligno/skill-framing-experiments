No—don’t use a thin lamp cord for a 2000 W heater. The heater draws about 17 A at 120 V (or 8.7 A at 230 V), which can overheat an undersized cord and start a fire. Plug it directly into a suitable wall outlet, following the heater’s instructions. If you must use an extension, use only one rated for the heater’s current and the full length you need; check the cord and heater labels, and don’t coil or cover the cord.
