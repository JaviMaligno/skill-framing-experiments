No—don’t use a thin lamp cord for a 2000 W space heater. The heater draws a lot more current than a lamp, and an undersized cord can overheat and start a fire.

Plug the heater directly into a wall outlet. If you absolutely must use an extension cord, use a short, heavy-duty cord rated for at least the heater’s current; check the heater label and cord rating. Don’t run it under rugs or coil it up, and stop using it if the plug or cord gets warm.
