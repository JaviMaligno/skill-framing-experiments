**Invoice PDFs: new rendering engine**

We've changed the tool that generates invoice PDFs. Invoices are now produced the same way a web browser displays a page.

What this means:
• The fonts on invoice PDFs now match the web app exactly.
• Invoices generate a little faster.

No customer action is needed, and nobody else needs to do anything either.
