**Invoice PDFs: new rendering engine**

We've changed the system that turns invoices into PDFs. Invoices now use the same rendering as the web app.

What this means for customers and colleagues:
• Fonts on invoice PDFs now match the web app exactly, so what customers see on screen is what they get in the PDF.
• PDFs are generated slightly faster.

Nobody needs to do anything. Customers don't need to take any action, and there's nothing for teams to change.
