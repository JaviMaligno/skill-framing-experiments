**CSV export: wrong dates in some exports from 6–17 Oct (now fixed)**

CSV exports created between 6 and 17 October had dates one day late for customers outside the UK. This affected accounts in time zones ahead of UTC. The bug is fixed, and new exports are correct.

Exports that were already created were not corrected automatically, so any affected file still has the wrong dates.

• **Support: if an affected customer gets in touch, tell them to run the export again.**
• **Finance: re-run your September close export before Monday.**
