You want a function that turns an invoice title into a URL-safe slug.

## Approach
1. Add `invoices/utils/slugs.py` with a pure `slugify_invoice_title()` function built on Django's `slugify`. It strips accents, lowercases, and turns spaces and punctuation into hyphens.
2. Add an optional `unique_invoice_slug()` for when the slug is stored on the model and has to be unique.
3. Add unit tests. The pure function needs no migration and no flag. If you later add a `slug` field to `Invoice` and use it in invoice URLs, that is billing feature work: put it behind a flag and get the migration reviewed.

## Code

`invoices/utils/slugs.py`
```python
from __future__ import annotations

from django.db.models import Model, QuerySet
from django.utils.text import slugify

DEFAULT_MAX_LENGTH = 80
FALLBACK_SLUG = "invoice"


def slugify_invoice_title(title: str | None, max_length: int = DEFAULT_MAX_LENGTH) -> str:
    """Turn an invoice title into an ASCII URL slug.

    "Factura Nº 2026/014 – Señor Ñandú" -> "factura-no-2026014-senor-nandu"
    """
    slug = slugify(title or "", allow_unicode=False)  # NFKD-normalises accents to ASCII
    if len(slug) > max_length:
        slug = slug[:max_length].rstrip("-")
    return slug or FALLBACK_SLUG


def unique_invoice_slug(
    title: str | None,
    queryset: QuerySet[Model],
    slug_field: str = "slug",
    max_length: int = DEFAULT_MAX_LENGTH,
) -> str:
    """Return a slug not already used in `queryset`. Adds -2, -3, ... when needed.

    Exclude the current instance from `queryset` when you update an existing row.
    """
    base = slugify_invoice_title(title, max_length)
    candidate = base
    n = 2
    while queryset.filter(**{slug_field: candidate}).exists():
        suffix = f"-{n}"
        candidate = f"{base[: max_length - len(suffix)].rstrip('-')}{suffix}"
        n += 1
    return candidate
```

`invoices/tests/test_slugs.py`
```python
import pytest

from invoices.utils.slugs import slugify_invoice_title


@pytest.mark.parametrize(
    ("title", "expected"),
    [
        ("Invoice #1042 — ACME Corp", "invoice-1042-acme-corp"),
        ("Factura Señor Ñandú", "factura-senor-nandu"),
        ("  Multiple   spaces  ", "multiple-spaces"),
        ("", "invoice"),
        (None, "invoice"),
        ("!!!", "invoice"),
    ],
)
def test_slugify_invoice_title(title: str | None, expected: str) -> None:
    assert slugify_invoice_title(title) == expected


def test_truncates_without_trailing_hyphen() -> None:
    slug = slugify_invoice_title("a" * 79 + " b", max_length=80)
    assert len(slug) <= 80
    assert not slug.endswith("-")
```

Example usage when the slug is stored on the model:
```python
invoice.slug = unique_invoice_slug(
    invoice.title, Invoice.objects.exclude(pk=invoice.pk)
)
```

## Verify
```powershell
pytest invoices/tests/test_slugs.py -v
```
If you use `unique_invoice_slug`, also add a unique constraint on the `slug` column. The check-then-write loop can race when two invoices with the same title are saved at once, and the constraint makes that fail cleanly instead of saving a duplicate.
