**Request:** get stale user accounts out of the Django admin in production.

## Why not just `DELETE`
- Deleting a `User` in Django **cascades**. Every `ForeignKey(User, on_delete=CASCADE)` row goes with it, which could include orders, invoices, audit logs and anything billing-related. Rows with `PROTECT` will make the delete fail partway, and `SET_NULL` rows will silently lose their link to the user.
- Billing or legal records may need to be kept.
- You can only reverse it by restoring a backup.

## What I need from you
1. **What counts as "old"?** For example, `last_login` more than 12 months ago, never logged in and joined more than 90 days ago, or `is_active=False`.
2. **Should any users be excluded?** Staff and superusers, anyone with a paid plan or invoices, or test accounts you want to keep.
3. **Is the goal a clean admin view or actually removing the data?** If it's just the admin, you don't need to delete anything.

## Proposed approach (small, reversible steps)

**Step 1: Fix the clutter without touching data.** Add a default filter to the admin so stale users are hidden:

```python
# accounts/admin.py
from datetime import timedelta
from django.contrib import admin
from django.contrib.auth.admin import UserAdmin
from django.contrib.auth import get_user_model
from django.db.models import QuerySet
from django.http import HttpRequest
from django.utils import timezone

User = get_user_model()

class ActivityFilter(admin.SimpleListFilter):
    title = "activity"
    parameter_name = "activity"

    def lookups(self, request: HttpRequest, model_admin: admin.ModelAdmin) -> list[tuple[str, str]]:
        return [("recent", "Active last 12 months"), ("stale", "Stale"), ("all", "All")]

    def queryset(self, request: HttpRequest, queryset: QuerySet) -> QuerySet:
        cutoff = timezone.now() - timedelta(days=365)
        value = self.value() or "recent"
        if value == "recent":
            return queryset.filter(last_login__gte=cutoff) | queryset.filter(date_joined__gte=cutoff)
        if value == "stale":
            return queryset.exclude(last_login__gte=cutoff).exclude(date_joined__gte=cutoff)
        return queryset

admin.site.unregister(User)

@admin.register(User)
class CustomUserAdmin(UserAdmin):
    list_filter = (ActivityFilter, *UserAdmin.list_filter)
```

**Step 2: If you want them out of the app, deactivate them instead of deleting.** Use a management command with a dry run:

```python
# accounts/management/commands/deactivate_stale_users.py
from datetime import timedelta
from typing import Any
from django.contrib.auth import get_user_model
from django.core.management.base import BaseCommand, CommandParser
from django.utils import timezone

class Command(BaseCommand):
    help = "Deactivate users with no login in N days (dry run by default)."

    def add_arguments(self, parser: CommandParser) -> None:
        parser.add_argument("--days", type=int, default=365)
        parser.add_argument("--apply", action="store_true")

    def handle(self, *args: Any, days: int, apply: bool, **opts: Any) -> None:
        cutoff = timezone.now() - timedelta(days=days)
        qs = (
            get_user_model().objects
            .filter(is_active=True, is_staff=False, is_superuser=False, date_joined__lt=cutoff)
            .exclude(last_login__gte=cutoff)
        )
        self.stdout.write(f"{qs.count()} users match (cutoff {cutoff:%Y-%m-%d}).")
        if apply:
            n = qs.update(is_active=False)
            self.stdout.write(self.style.SUCCESS(f"Deactivated {n}."))
```
