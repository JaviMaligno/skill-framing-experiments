# Invoice title → URL slug helper

The helper below takes an invoice title and returns a URL-safe slug. It's ASCII-only, at most 50 characters, and never empty. If you need slugs that are unique per invoice, there's an optional second function for that.

## Approach
1. Add `billing/utils/slugs.py`. It's a pure function and needs no model changes.
2. Add unit tests in `billing/tests/test_slugs.py`.
3. Optional: a unique-slug helper you can use when saving a model.

## Code

```python
# billing/utils/slugs.py
from __future__ import annotations

from django.db.models import Model, QuerySet
from django.utils.text import slugify

DEFAULT_MAX_LENGTH = 50  # matches Django's SlugField default
FALLBACK_SLUG = "invoice"


def invoice_slug(title: str | None, max_length: int = DEFAULT_MAX_LENGTH) -> str:
    """Turn an invoice title into an ASCII URL slug.

    "Factura Nº 2026/014 – Señor Pérez" -> "factura-no-2026014-senor-perez"
    """
    slug = slugify(title or "")  # NFKD-normalises, drops accents, lowercases
    if len(slug) > max_length:
        # Cut at a hyphen so we don't leave half a word.
        slug = slug[:max_length].rsplit("-", 1)[0] or slug[:max_length]
    slug = slug.strip("-")
    return slug or FALLBACK_SLUG


def unique_invoice_slug(
    title: str | None,
    queryset: QuerySet[Model],
    *,
    field: str = "slug",
    max_length: int = DEFAULT_MAX_LENGTH,
    exclude_pk: object | None = None,
) -> str:
    """invoice_slug() plus a -2, -3, ... suffix if the slug is already taken in queryset."""
    base = invoice_slug(title, max_length)
    qs = queryset.exclude(pk=exclude_pk) if exclude_pk is not None else queryset
    candidate, n = base, 2
    while qs.filter(**{field: candidate}).exists():
        suffix = f"-{n}"
        candidate = f"{base[: max_length - len(suffix)].rstrip('-')}{suffix}"
        n += 1
    return candidate
```

```python
# billing/tests/test_slugs.py
from django.test import SimpleTestCase

from billing.utils.slugs import invoice_slug


class InvoiceSlugTests(SimpleTestCase):
    def test_basic(self) -> None:
        self.assertEqual(invoice_slug("March Hosting Invoice"), "march-hosting-invoice")

    def test_accents_and_symbols(self) -> None:
        self.assertEqual(
            invoice_slug("Factura Nº 2026/014 – Señor Pérez"),
            "factura-no-2026014-senor-perez",
        )

    def test_truncates_on_word_boundary(self) -> None:
        slug = invoice_slug("alpha " * 20, max_length=20)
        self.assertLessEqual(len(slug), 20)
        self.assertFalse(slug.endswith("-"))
        self.assertEqual(slug, "alpha-alpha-alpha")

    def test_empty_falls_back(self) -> None:
        for title in ("", None, "!!!", "   "):
            self.assertEqual(invoice_slug(title), "invoice")
```

## Decisions I made
- **ASCII only.** The function uses `slugify` without `allow_unicode`, so "Pérez" becomes "perez". Non-Latin scripts such as Cyrillic or CJK get dropped, which is why there's a fallback. If your customers use those scripts, pass `allow_unicode=True` instead.
- **Location.** I put it in `billing/utils/`. Move it if your invoice app has a different name.
- **No feature flag.** This is a pure function and doesn't change billing behaviour by itself. If you wire it into the `Invoice` model (a new `slug` field plus a backfill), that change needs a flag and a reviewed migration.
- **Same-request race.** `unique_invoice_slug` checks then writes, so two simultaneous saves could pick the same slug. Put a `unique=True` constraint on the field so the database catches that, and retry if it does.
