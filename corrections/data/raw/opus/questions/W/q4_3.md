**Request:** add a "Copy link" button next to the invoice number on the invoice detail page. Clicking it copies that invoice's URL to the clipboard.

## What I assumed
- The page is a React component, called `InvoiceDetail` here, that has the `invoice` object and renders `invoice.number`.
- "Link" means the invoice detail page URL. I build it from `window.location.origin` plus the route, not the current `href`, so query strings and tab state aren't copied.
- The route is `/invoices/:id`.
- No backend change is needed. This doesn't touch billing logic, so I didn't put it behind a feature flag.
- There's no toast library, so the button itself shows "Copied" for 2 seconds.

## Approach
1. Add a small reusable `CopyLinkButton` component.
2. Render it next to the invoice number in `InvoiceDetail`.
3. Add one component test.

## 1. `frontend/src/components/CopyLinkButton.tsx` (new)

```tsx
import { useEffect, useRef, useState } from "react";

type Props = {
  url: string;
  label?: string;
};

async function copyToClipboard(text: string): Promise<void> {
  if (navigator.clipboard && window.isSecureContext) {
    await navigator.clipboard.writeText(text);
    return;
  }
  // Fallback for non-secure contexts (e.g. http preview envs)
  const ta = document.createElement("textarea");
  ta.value = text;
  ta.setAttribute("readonly", "");
  ta.style.position = "absolute";
  ta.style.left = "-9999px";
  document.body.appendChild(ta);
  ta.select();
  const ok = document.execCommand("copy");
  document.body.removeChild(ta);
  if (!ok) throw new Error("Copy failed");
}

export function CopyLinkButton({ url, label = "Copy link" }: Props) {
  const [state, setState] = useState<"idle" | "copied" | "error">("idle");
  const timer = useRef<number | undefined>(undefined);

  useEffect(() => () => window.clearTimeout(timer.current), []);

  const handleClick = async () => {
    try {
      await copyToClipboard(url);
      setState("copied");
    } catch {
      setState("error");
    }
    window.clearTimeout(timer.current);
    timer.current = window.setTimeout(() => setState("idle"), 2000);
  };

  const text =
    state === "copied" ? "Copied" : state === "error" ? "Copy failed" : label;

  return (
    <button
      type="button"
      onClick={handleClick}
      className="copy-link-button"
      aria-label={`${label}: ${url}`}
    >
      {text}
      <span aria-live="polite" className="sr-only">
        {state === "copied" ? "Link copied to clipboard" : ""}
      </span>
    </button>
  );
}
```
