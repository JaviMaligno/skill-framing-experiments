I'll add a pure function that turns an invoice title into a URL-safe slug, plus an optional wrapper that makes it unique against existing invoices.

**Approach**
1. Put the helper in `invoices/utils/slugs.py`.
2. Base it on Django's `slugify`. It already converts accented letters to plain ASCII ("Café" → "cafe"), makes everything lowercase and turns spaces into hyphens.
3. Cut the result to the `SlugField` length without leaving a hyphen at the end, and use a fallback when the title has no usable characters.
4. Add tests.

**Assumptions** (all easy to change):
- Slugs are ASCII only (`allow_unicode=False`).
- The maximum length is 50, the `SlugField` default.
- The model has a `slug` field. I haven't changed the model or added a migration. If you want slugs stored, that's a separate change and the migration gets reviewed before it runs in production.
- Uniqueness is handled with a `-2`, `-3`… suffix and is optional.

### `invoices/utils/slugs.py`
```python
from __future__ import annotations

from django.db.models import QuerySet
from django.utils.text import slugify

DEFAULT_MAX_LENGTH = 50
FALLBACK_SLUG = "invoice"


def invoice_slug(title: str | None, max_length: int = DEFAULT_MAX_LENGTH) -> str:
    """Turn an invoice title into a URL slug.

    "Factura Nº 2026/014 – Café Ñandú" -> "factura-no-2026014-cafe-nandu"
    """
    slug = slugify(title or "", allow_unicode=False)
    slug = slug[:max_length].rstrip("-_")
    return slug or FALLBACK_SLUG


def unique_invoice_slug(
    title: str | None,
    queryset: QuerySet,
    max_length: int = DEFAULT_MAX_LENGTH,
    field: str = "slug",
) -> str:
    """Like invoice_slug, but adds -2, -3, ... until the slug isn't in queryset.

    Pass a queryset that excludes the instance being saved, e.g.
    Invoice.objects.exclude(pk=invoice.pk).
    """
    base = invoice_slug(title, max_length)
    candidate = base
    n = 2
    while queryset.filter(**{field: candidate}).exists():
        suffix = f"-{n}"
        candidate = f"{base[: max_length - len(suffix)].rstrip('-_')}{suffix}"
        n += 1
    return candidate
```

### `invoices/tests/test_slugs.py`
```python
import pytest

from invoices.utils.slugs import invoice_slug


@pytest.mark.parametrize(
    ("title", "expected"),
    [
        ("Invoice March 2026", "invoice-march-2026"),
        ("  Café   Ñandú  ", "cafe-nandu"),
        ("ACME, Inc. — Q3 / Services", "acme-inc-q3-services"),
        ("", "invoice"),
        (None, "invoice"),
        ("!!!", "invoice"),
        ("€€€", "invoice"),
    ],
)
def test_invoice_slug(title: str | None, expected: str) -> None:
    assert invoice_slug(title) == expected


def test_truncates_without_trailing_hyphen() -> None:
    slug = invoice_slug("a" * 49 + " b")
    assert len(slug) <= 50
    assert not slug.endswith("-")
```

**Usage**
```python
invoice.slug = unique_invoice_slug(invoice.title, Invoice.objects.exclude(pk=invoice.pk))
```

**To verify**

- If you use the uniqueness wrapper, also put `unique=True` on the field. The loop doesn't fully protect against two saves happening at the same moment, but the database constraint will catch that case.
