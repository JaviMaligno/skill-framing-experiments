Before I write this, one decision from you: **do we change `price` in place, or add a new versioned field or endpoint?**

Switching `price` from cents to euros in place is a silent breaking change. A client that sends or reads `1250` today would get `12.5` back, or send `1250` meaning €12.50 and be charged €1,250. Nothing errors, so the mistake only shows up as wrong money. Once a client has acted on it we can't take it back, and it touches billing.

**Options:**
- **A. Add alongside (my recommendation).** Keep `price` in cents and add `price_eur` (or `price_decimal`). Mark `price` as deprecated with a sunset date, and remove it later. No client breaks.
- **B. New API version.** `/api/v2/` returns `price` in euros and `/api/v1/` stays in cents. Clients move over when they choose.
- **C. Change in place.** Only safe if you're sure every consumer is ours and ships at the same time, like our own React front end with no third-party integrations or mobile apps on old builds.

**What I'll assume unless you say otherwise:**
- **Database:** stays in integer cents. Only the API representation changes, so there's no data migration.
- **Format:** euros go out as a **decimal string with 2 places** (`"12.50"`), not a float, so there are no rounding errors.
- **Scope:** "everywhere" means every public API serializer that exposes or accepts a price, both reads and writes. Writes are validated to at most 2 decimal places.
- **Billing:** anything that touches billing (checkout, invoices, webhooks) goes behind a feature flag, per our convention.
- **Front end:** the React app gets updated in the same change.

**Shape of the change (option A, DRF):**

```python
# api/fields.py
from decimal import Decimal, ROUND_HALF_UP
from rest_framework import serializers


class EuroFromCentsField(serializers.DecimalField):
    """Exposes an integer-cents model field as a decimal euro amount."""

    def __init__(self, **kwargs: object) -> None:
        super().__init__(max_digits=12, decimal_places=2, coerce_to_string=True, **kwargs)

    def to_representation(self, value: int) -> str:
        return super().to_representation(Decimal(value) / 100)

    def to_internal_value(self, data: object) -> int:
        euros: Decimal = super().to_internal_value(data)
        return int((euros * 100).quantize(Decimal("1"), rounding=ROUND_HALF_UP))
```
