**Request:** add a "copy link" button next to the invoice number on the invoice detail page. Clicking it copies the invoice's URL to the clipboard.

I don't have access to the repo from this session, so I wrote this against the usual layout for our stack. The assumptions are listed at the end. Adjust paths and names where they differ.

## Approach
1. New small component `CopyLinkButton` (reusable, no invoice logic in it).
2. Render it next to the invoice number in `InvoiceDetail`, behind a feature flag. The button doesn't change any billing behaviour, but it is on a billing page and our convention says to flag that.
3. Add the flag on the Django side.
4. Write a unit test for the button.

No backend logic changes and no migrations beyond the flag row.

## Changes

**`frontend/src/components/CopyLinkButton.tsx`** (new)
```tsx
import { useEffect, useRef, useState } from "react";

type Props = {
  url: string;
  label?: string;
};

async function copyToClipboard(text: string): Promise<void> {
  if (navigator.clipboard && window.isSecureContext) {
    await navigator.clipboard.writeText(text);
    return;
  }
  // Fallback for non-secure contexts (e.g. local http on a LAN IP)
  const ta = document.createElement("textarea");
  ta.value = text;
  ta.setAttribute("readonly", "");
  ta.style.position = "absolute";
  ta.style.left = "-9999px";
  document.body.appendChild(ta);
  ta.select();
  const ok = document.execCommand("copy");
  document.body.removeChild(ta);
  if (!ok) throw new Error("copy failed");
}

export function CopyLinkButton({ url, label = "Copy link" }: Props) {
  const [state, setState] = useState<"idle" | "copied" | "error">("idle");
  const timer = useRef<number>();

  useEffect(() => () => window.clearTimeout(timer.current), []);

  const onClick = async () => {
    try {
      await copyToClipboard(url);
      setState("copied");
    } catch {
      setState("error");
    }
    window.clearTimeout(timer.current);
    timer.current = window.setTimeout(() => setState("idle"), 2000);
  };

  const text = state === "copied" ? "Copied!" : state === "error" ? "Couldn't copy" : label;

  return (
    <button
      type="button"
      className="copy-link-button"
      onClick={onClick}
      aria-label={`${label}: ${url}`}
      title={url}
    >
      {text}
      <span aria-live="polite" className="sr-only">
        {state === "copied" ? "Link copied to clipboard" : ""}
      </span>
    </button>
  );
}
```

**`frontend/src/pages/invoices/InvoiceDetail.tsx`** (edit the header)
```tsx
import { CopyLinkButton } from "@/components/CopyLinkButton";
import { useFeatureFlag } from "@/lib/flags";

// inside the component, where `invoice` is loaded:
const showCopyLink = useFeatureFlag("invoice_copy_link");
const invoiceUrl = `${window.location.origin}/invoices/${invoice.id}`;

// replace the invoice-number heading with:
<div className="invoice-header__number">
  <h1>Invoice {invoice.number}</h1>
  {showCopyLink && <CopyLinkButton url={invoiceUrl} />}
</div>
```
The URL is built from `invoice.id` rather than `window.location.href`. That way query strings, tabs and UTM parameters don't end up in the copied link.

**Small CSS** (wherever the invoice header styles live)

**Flag (Django, assuming django-waffle)**
```powershell
python manage.py waffle_flag invoice_copy_link --create --staff
```
This turns it on for staff first. Use `--everyone` when you roll it out to all users.

**`frontend/src/components/CopyLinkButton.test.tsx`**
```tsx
import { render, screen, fireEvent, waitFor } from "@testing-library/react";
import { CopyLinkButton } from "./CopyLinkButton";

test("copies the url and shows confirmation", async () => {
  const writeText = vi.fn().mockResolvedValue(undefined);
  Object.assign(navigator, { clipboard: { writeText } });
  Object.defineProperty(window, "isSecureContext", { value: true, configurable: true });

  render(<CopyLinkButton url="https://app.example.com/invoices/42" />);
  fireEvent.click(screen.getByRole("button"));

  await waitFor(() => expect(screen.getByRole("button")).toHaveTextContent("Copied!"));
  expect(writeText).toHaveBeenCalledWith("https://app.example.com/invoices/42");
});
```

## Assumptions (change if wrong)
- **Paths:** the invoice page is `InvoiceDetail.tsx`, it has an `invoice` object with `id` and `number`, and the route is `/invoices/:id`.
- **Flag hook:** a `useFeatureFlag` hook exists and reads waffle flags. If we use another flag system, swap the hook and the command.
- **Tests:** we use Vitest (`vi.fn`). For Jest, use `jest.fn`.
- **Styling:** the button is plain text. If we have an icon set or a `<Button>` component in the design system, use that instead.
