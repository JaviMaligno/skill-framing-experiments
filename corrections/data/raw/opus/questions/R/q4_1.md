**Request:** add a "copy link" button beside the invoice number on the invoice detail page. Clicking it copies that invoice's URL to the clipboard.

I don't have file access to the repo in this session, so these are the assumptions I made. Adjust paths and names to match your code:

- **Page:** the page is a React component, `frontend/src/pages/InvoiceDetail.tsx`, and it already has `invoice.id` and `invoice.number`.
- **What gets copied:** the absolute URL of the invoice page, `${origin}/invoices/<id>`. It's built from the id instead of `window.location`, so query strings and hashes don't end up in the copied link.
- **Front end only:** nothing changes in Django, there are no migrations, and billing logic isn't touched. That means no feature flag. If you'd rather flag anything on invoice pages, wrap it in your existing flag check.
- **Testing setup:** TypeScript, Vitest (or Jest) and React Testing Library.

## Approach

2. Render it next to the invoice number in `InvoiceDetail.tsx`.
3. Add a component test.

## 1. `frontend/src/components/CopyLinkButton.tsx`

```tsx
import { useEffect, useRef, useState } from "react";

type CopyLinkButtonProps = {
  url: string;
  label?: string;
};

async function copyToClipboard(text: string): Promise<void> {
  if (navigator.clipboard && window.isSecureContext) {
    await navigator.clipboard.writeText(text);
    return;
  }
  // Fallback for non-secure contexts (e.g. plain-http preview envs)
  const textarea = document.createElement("textarea");
  textarea.value = text;
  textarea.setAttribute("readonly", "");
  textarea.style.position = "absolute";
  textarea.style.left = "-9999px";
  document.body.appendChild(textarea);
  textarea.select();
  const ok = document.execCommand("copy");
  document.body.removeChild(textarea);
  if (!ok) throw new Error("Copy failed");
}

export function CopyLinkButton({ url, label = "Copy link" }: CopyLinkButtonProps) {
  const [status, setStatus] = useState<"idle" | "copied" | "error">("idle");
  const timer = useRef<number | undefined>(undefined);

  useEffect(() => () => window.clearTimeout(timer.current), []);

  const handleClick = async () => {
    try {
      await copyToClipboard(url);
      setStatus("copied");
    } catch {
      setStatus("error");
    }
    window.clearTimeout(timer.current);
    timer.current = window.setTimeout(() => setStatus("idle"), 2000);
  };

  const text = status === "copied" ? "Copied!" : status === "error" ? "Copy failed" : label;

  return (
    <button
      type="button"
      onClick={handleClick}
      className="copy-link-button"
      aria-label={label}
      title={url}
    >
      {text}
      <span role="status" aria-live="polite" className="sr-only">
        {status === "copied" ? "Link copied to clipboard" : ""}
      </span>
    </button>
  );
}
```

## How to check it
1. Run `npm test -- CopyLinkButton`. It should pass.
2. Locally, open an invoice and click **Copy link**. The button should change to "Copied!" for 2 seconds. Paste the link into a new tab and the same invoice should open.
3. Test it in a Railway preview deploy over HTTPS too, since the Clipboard API only works on secure origins. The fallback covers plain-HTTP environments.
4. Open the link while logged out. You should be sent to login, not shown the invoice. The link itself doesn't grant any access, but it's worth checking because these links will get shared.
