## Recommended approach: Option B (add a field, then remove the old one)

1. **Serializer:** add `price_eur` as a decimal string such as `"19.99"`, not a float, so no rounding errors. Keep `price` (cents) and mark it deprecated in the API docs.
2. **Write endpoints:** accept either `price_eur` or `price`, and return an error if both are sent and don't match.
3. **Flag:** `API_PRICE_IN_EUROS` controls whether `price` itself switches to euros in the clients we own.
4. **React:** read `price_eur` everywhere.
5. **Later:** announce a removal date and drop `price` (cents).

No migration is needed. Storage stays in integer cents and only the API layer converts.

### Code (this assumes DRF serializers; adjust names to match your code)

```python
# core/api/fields.py
from decimal import Decimal, ROUND_HALF_UP
from rest_framework import serializers

class CentsAsEurosField(serializers.DecimalField):
    """Exposes an integer-cents model field as a euro decimal string."""

    def __init__(self, **kwargs: object) -> None:
        kwargs.setdefault("max_digits", 12)
        kwargs.setdefault("decimal_places", 2)
        kwargs.setdefault("coerce_to_string", True)
        super().__init__(**kwargs)

    def to_representation(self, value: int) -> str:
        euros = (Decimal(value) / 100).quantize(Decimal("0.01"), rounding=ROUND_HALF_UP)
        return super().to_representation(euros)

    def to_internal_value(self, data: object) -> int:
        euros: Decimal = super().to_internal_value(data)
        return int((euros * 100).quantize(Decimal("1"), rounding=ROUND_HALF_UP))
```

class ProductSerializer(serializers.ModelSerializer):

    class Meta:
        model = Product
        fields = [..., "price", "price_eur"]
        extra_kwargs = {"price": {"required": False}}

    def validate(self, attrs: dict) -> dict:
        # price_eur and price share source="price"; DRF keeps the later one.
        # Check for a mismatch on the raw input.
        raw = self.initial_data
        if "price" in raw and "price_eur" in raw:
            eur_cents = CentsAsEurosField().to_internal_value(raw["price_eur"])
            if int(raw["price"]) != eur_cents:
                raise serializers.ValidationError("price and price_eur disagree.")
        return attrs
