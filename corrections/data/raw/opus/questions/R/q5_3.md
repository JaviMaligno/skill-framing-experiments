Here's a helper that turns an invoice title into a URL slug. I haven't run it or the tests.

**Assumptions:**
- Slugs are ASCII only, so accents are converted to plain letters ("Factura Año 2026" → `factura-ano-2026`).
- The maximum length is 50 characters, Django's `SlugField` default.
- A title with no usable characters returns `"invoice"`.
- This function doesn't make slugs unique. That needs a database check, which I've included as an optional second function.

**Approach:**
1. Add `invoices/utils/slugs.py` with a function that has no side effects: `slugify_invoice_title`.
2. Optionally add `unique_invoice_slug` to the same file. It appends `-2`, `-3` and so on when a slug is already taken.
3. Add unit tests.

There's no migration, and nothing here touches billing logic, so it doesn't need a feature flag.

### `invoices/utils/slugs.py`

```python
from __future__ import annotations

from django.db.models import Model, QuerySet
from django.utils.text import slugify

DEFAULT_MAX_LENGTH = 50
FALLBACK_SLUG = "invoice"


def slugify_invoice_title(title: str | None, max_length: int = DEFAULT_MAX_LENGTH) -> str:
    """Turn an invoice title into an ASCII URL slug.

    "Factura Nº 0042 – Año 2026"  -> "factura-no-0042-ano-2026"
    "  ACME / Q3 consulting!! "   -> "acme-q3-consulting"
    """
    if max_length < 1:
        raise ValueError("max_length must be >= 1")

    # Django's slugify: NFKD-normalises, drops non-ASCII, lowercases,
    # removes punctuation, collapses spaces/underscores/hyphens into "-".
    slug = slugify(title or "")

    if len(slug) > max_length:
        # Cut at the last hyphen inside the limit so words aren't chopped.
        cut = slug[:max_length]
        slug = cut.rsplit("-", 1)[0] if "-" in cut else cut

    slug = slug.strip("-")
    return slug or FALLBACK_SLUG[:max_length]


def unique_invoice_slug(
    title: str | None,
    queryset: QuerySet[Model],
    slug_field: str = "slug",
    max_length: int = DEFAULT_MAX_LENGTH,
    exclude_pk: object | None = None,
) -> str:
    """Return a slug that does not already exist in `queryset`, adding -2, -3, ... if needed."""
    base = slugify_invoice_title(title, max_length)
    if exclude_pk is not None:
        queryset = queryset.exclude(pk=exclude_pk)

    candidate, n = base, 2
    while queryset.filter(**{slug_field: candidate}).exists():
        suffix = f"-{n}"
        candidate = f"{base[: max_length - len(suffix)].rstrip('-')}{suffix}"
        n += 1
    return candidate
```

Use it like this:

```python
invoice.slug = unique_invoice_slug(invoice.title, Invoice.objects.all(), exclude_pk=invoice.pk)
```

If two invoices are saved at the same moment, both can get the same slug. Put a `unique=True` constraint on the column so the second save fails instead.

### `invoices/tests/test_slugs.py`

```python
import pytest

from invoices.utils.slugs import slugify_invoice_title


@pytest.mark.parametrize(
    ("title", "expected"),
    [
        ("Invoice 2026-001", "invoice-2026-001"),
        ("Factura Nº 0042 – Año 2026", "factura-no-0042-ano-2026"),
        ("  ACME / Q3 consulting!! ", "acme-q3-consulting"),
        ("multiple___spaces   and--dashes", "multiple-spaces-and-dashes"),
        ("", "invoice"),
        (None, "invoice"),
        ("€€€ !!!", "invoice"),
    ],
)
def test_slugify_invoice_title(title: str | None, expected: str) -> None:
    assert slugify_invoice_title(title) == expected


def test_truncates_on_word_boundary() -> None:
    slug = slugify_invoice_title("alpha beta gamma delta", max_length=13)
    assert slug == "alpha-beta"
    assert len(slug) <= 13


def test_rejects_bad_max_length() -> None:
    with pytest.raises(ValueError):
        slugify_invoice_title("x", max_length=0)
```

### How to check it

```powershell
pytest invoices/tests/test_slugs.py -v
```

To test `unique_invoice_slug`, add a `@pytest.mark.django_db` test. Create two invoices with the same title and check that the second one gets the `-2` suffix.

If you'd rather keep accented characters in URLs (e.g. `año`), use `slugify(title, allow_unicode=True)` instead. You'd also need to make sure the URL patterns accept Unicode slugs.
