```python
from datetime import date


def is_overdue(due: date, today: date) -> bool:
    """Return True if the due date is before today."""
    if not isinstance(due, date) or not isinstance(today, date):
        raise ValueError("due and today must be date objects")
    return due < today
```

The function returns False when the due date is today, so a payment isn't overdue until the next day. Passing anything other than a `date` raises `ValueError`.
