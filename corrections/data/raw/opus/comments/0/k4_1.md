```python
from decimal import Decimal, ROUND_HALF_UP, InvalidOperation


def total_with_vat(net: Decimal, rate: Decimal) -> Decimal:
    """Return net plus VAT at the given rate, rounded half up to 2 decimals."""
    if not isinstance(net, Decimal) or not isinstance(rate, Decimal):
        raise ValueError("net and rate must be Decimal instances")
    if not net.is_finite() or not rate.is_finite():
        raise ValueError("net and rate must be finite")
    if net < 0:
        raise ValueError("net must be non-negative")
    if rate < 0:
        raise ValueError("rate must be non-negative")
    try:
        return (net * (Decimal(1) + rate)).quantize(Decimal("0.01"), rounding=ROUND_HALF_UP)
    except InvalidOperation as exc:
        raise ValueError("could not compute total") from exc
```

The function expects `rate` as a fraction, so 21% VAT is `Decimal("0.21")`. It rounds only the final total, which means the small rounding error from computing VAT and adding it to the net never happens.
