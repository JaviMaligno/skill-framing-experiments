```python
from typing import Any


def dedupe_payments(payments: list[dict[str, Any]]) -> list[dict[str, Any]]:
    """Return one payment per ref, keeping the one with the lowest id."""
    canonical: dict[Any, dict[str, Any]] = {}
    for payment in payments:
        if not isinstance(payment, dict) or "id" not in payment or "ref" not in payment:
            raise ValueError(f"Payment must be a dict with 'id' and 'ref': {payment!r}")
        ref = payment["ref"]
        current = canonical.get(ref)
        if current is None or payment["id"] < current["id"]:
            canonical[ref] = payment
    return list(canonical.values())
```

The output keeps refs in the order they first appear in the input, so arrival order doesn't affect which record is chosen. If two records share both a ref and an id, the first one seen is kept.
