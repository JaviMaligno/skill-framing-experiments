```python
from datetime import date, timedelta


def billing_period_end(api_end: date) -> date:
    """Return the last billed day for a period end that the bank API reports as exclusive."""
    if not isinstance(api_end, date):
        raise ValueError(f"api_end must be a date, got {type(api_end).__name__}")
    if api_end == date.min:
        raise ValueError("api_end cannot be date.min; no earlier day exists")
    return api_end - timedelta(days=1)
```

The API reports the day after the last billed day, so the function subtracts one day. `timedelta` takes care of month ends, year ends and leap years: an `api_end` of 2026-03-01 gives 2026-02-28, and 2024-03-01 gives 2024-02-29.
