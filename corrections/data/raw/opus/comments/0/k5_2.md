```python
from datetime import date


def is_overdue(due: date, today: date) -> bool:
    """Return True if the due date is earlier than today."""
    if not isinstance(due, date) or not isinstance(today, date):
        raise ValueError("due and today must be datetime.date instances")
    return due < today
```

An invoice that's due today doesn't count as overdue. It only becomes overdue the day after its due date.
