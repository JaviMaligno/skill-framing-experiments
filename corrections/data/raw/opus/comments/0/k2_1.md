```python
import time
from collections.abc import Callable, Iterable
from typing import TypeVar

T = TypeVar("T")

MIN_INTERVAL_S = 1.1


def send_all(reminders: Iterable[T], send: Callable[[T], object]) -> int:
    """Return the number of reminders sent, starting each send call at least 1.1 s after the previous one."""
    if not callable(send):
        raise ValueError("send must be callable")

    count = 0
    last_start: float | None = None
    for reminder in reminders:
        if last_start is not None:
            remaining = MIN_INTERVAL_S - (time.monotonic() - last_start)
            if remaining > 0:
                time.sleep(remaining)
        last_start = time.monotonic()
        send(reminder)
        count += 1
    return count
```

The 1.1 s gap is measured between the starts of consecutive `send` calls using `time.monotonic()`. That keeps you under the provider's one-per-rolling-second limit even if a call is slow, and the clock can't jump if the system time changes. If `send` raises, the error stops the loop, so reminders after the failed one aren't sent.
