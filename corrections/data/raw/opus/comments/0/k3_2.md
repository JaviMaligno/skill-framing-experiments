```python
from typing import Any


def dedupe_payments(payments: list[dict[str, Any]]) -> list[dict[str, Any]]:
    """Return one payment per ref, keeping the one with the lowest id, ordered by first appearance of each ref."""
    canonical: dict[Any, dict[str, Any]] = {}
    for index, payment in enumerate(payments):
        if not isinstance(payment, dict):
            raise ValueError(f"payment at index {index} is not a dict")
        if "id" not in payment or "ref" not in payment:
            raise ValueError(f"payment at index {index} is missing 'id' or 'ref'")
        ref = payment["ref"]
        current = canonical.get(ref)
        try:
            if current is None or payment["id"] < current["id"]:
                canonical[ref] = payment
        except TypeError as exc:
            raise ValueError(f"payment ids for ref {ref!r} are not comparable") from exc
    return list(canonical.values())
```

Each ref keeps the record with the lowest `id`, whatever order the duplicates arrive in. The output follows the order in which each ref first appears, and the function raises `ValueError` if a record is missing `id` or `ref` or if ids can't be compared.
