```python
from decimal import Decimal, ROUND_HALF_UP

_CENT = Decimal("0.01")


def total_with_vat(net: Decimal, rate: Decimal) -> Decimal:
    """Return the net amount plus VAT at the given rate, rounded half up to 2 decimals."""
    if not isinstance(net, Decimal) or not isinstance(rate, Decimal):
        raise ValueError("net and rate must be Decimal instances")
    if not net.is_finite() or not rate.is_finite():
        raise ValueError("net and rate must be finite")
    if rate < 0:
        raise ValueError(f"rate must be non-negative, got {rate}")
    return (net * (1 + rate)).quantize(_CENT, rounding=ROUND_HALF_UP)
```

The function expects `rate` as a fraction, so 21% is `Decimal("0.21")`, and it rounds only the final total. Negative `net` values are allowed so credit notes work.
