```python
def format_invoice_number(year: int, seq: int) -> str:
    """Return the invoice number formatted as 'INV-YYYY-NNNN'."""
    if not 1000 <= year <= 9999:
        raise ValueError(f"year must be a four-digit number, got {year}")
    if not 1 <= seq <= 9999:
        raise ValueError(f"seq must be between 1 and 9999, got {seq}")
    return f"INV-{year}-{seq:04d}"
```

`format_invoice_number(2026, 42)` returns `'INV-2026-0042'`. It raises `ValueError` if `seq` is over 9999 instead of returning a longer number, because then the invoice numbers would no longer all be the same length.
