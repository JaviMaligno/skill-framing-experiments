```python
import time
from collections.abc import Callable, Iterable
from typing import TypeVar

T = TypeVar("T")

SEND_INTERVAL_SECONDS: float = 1.1


def send_all(reminders: Iterable[T], send: Callable[[T], object]) -> int:
    """Return the number of reminders sent, keeping call starts at least 1.1 s apart."""
    if not callable(send):
        raise ValueError("send must be callable")

    count = 0
    last_start: float | None = None
    for reminder in reminders:
        if last_start is not None:
            wait = SEND_INTERVAL_SECONDS - (time.monotonic() - last_start)
            if wait > 0:
                time.sleep(wait)
        last_start = time.monotonic()
        send(reminder)
        count += 1
    return count
```

The 1.1 s is measured from the start of one `send` to the start of the next, using `time.monotonic()`, so slow calls don't add extra delay and clock changes don't break the spacing. It only waits between calls, so there's no pause before the first send or after the last one. If `send` raises, the exception goes straight to the caller and the remaining reminders aren't sent.
