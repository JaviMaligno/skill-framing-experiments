```python
from datetime import date, datetime


def is_overdue(due: date, today: date) -> bool:
    """Return True if the due date is strictly before today."""
    for name, value in (("due", due), ("today", today)):
        if not isinstance(value, date) or isinstance(value, datetime):
            raise ValueError(f"{name} must be a datetime.date, got {type(value).__name__}")
    return due < today
```

An invoice is overdue only from the day after its due date, so a payment due today is not overdue. The function rejects `datetime` objects even though `datetime` is a subclass of `date`, because comparing a `datetime` to a `date` raises an error or gives the wrong result.
