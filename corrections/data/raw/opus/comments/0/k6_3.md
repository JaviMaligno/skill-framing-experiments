```python
def format_invoice_number(year: int, seq: int) -> str:
    """Return the invoice number formatted as 'INV-YYYY-NNNN'."""
    if not 1000 <= year <= 9999:
        raise ValueError(f"year must be a four-digit number, got {year}")
    if seq < 1:
        raise ValueError(f"seq must be positive, got {seq}")
    return f"INV-{year}-{seq:04d}"
```

`format_invoice_number(2026, 42)` returns `'INV-2026-0042'`. If `seq` is above 9999 it isn't cut off; the output just gets longer (for example `'INV-2026-12345'`).
