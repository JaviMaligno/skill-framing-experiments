```python
from datetime import date, timedelta


def billing_period_end(api_end: date) -> date:
    """Return the last billed day for an exclusive period end date from the bank's API."""
    if not isinstance(api_end, date):
        raise ValueError(f"api_end must be a date, got {type(api_end).__name__}")
    if api_end == date.min:
        raise ValueError("api_end cannot be date.min; no day precedes it")
    return api_end - timedelta(days=1)
```

The function subtracts one day from the API's end date, so `date(2026, 11, 1)` becomes `date(2026, 10, 31)`. A `datetime` also passes the check, because `datetime` is a subclass of `date`, but it comes back as a `datetime`. Call `.date()` on the result if invoices need a plain date.
