```python
from datetime import date, timedelta


def billing_period_end(api_end: date) -> date:
    """Return the last billed day (inclusive) for an exclusive API period end date."""
    if not isinstance(api_end, date):
        raise ValueError(f"api_end must be a date, got {type(api_end).__name__}")
    if api_end == date.min:
        raise ValueError("api_end cannot be date.min; no earlier day exists")
    return api_end - timedelta(days=1)
```

The API's end date is exclusive, so the last billed day is the day before it. The function rejects anything that isn't a date (a `datetime` counts as a date, since it subclasses `date`) and refuses `date.min`, because there's no earlier day to return.
