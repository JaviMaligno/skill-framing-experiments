```python
from decimal import Decimal, ROUND_HALF_UP


def total_with_vat(net: Decimal, rate: Decimal) -> Decimal:
    """Return the net amount plus VAT, rounded to 2 decimals using half-up rounding."""
    if not isinstance(net, Decimal) or not isinstance(rate, Decimal):
        raise ValueError("net and rate must be Decimal instances")
    if not net.is_finite() or not rate.is_finite():
        raise ValueError("net and rate must be finite")
    if net < 0:
        raise ValueError("net must be non-negative")
    if not (Decimal("0") <= rate <= Decimal("1")):
        raise ValueError("rate must be a fraction between 0 and 1 (e.g. Decimal('0.21'))")

    total = net * (Decimal("1") + rate)
    return total.quantize(Decimal("0.01"), rounding=ROUND_HALF_UP)
```

`rate` must be a fraction, so 21% VAT is `Decimal("0.21")`, not `Decimal("21")`. Rounding only happens once, on the final total, so you don't get errors from rounding the VAT amount separately first.
