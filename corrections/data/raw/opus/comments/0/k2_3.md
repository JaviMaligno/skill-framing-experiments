```python
import time
from collections.abc import Callable, Iterable
from typing import TypeVar

T = TypeVar("T")

SEND_INTERVAL_SECONDS: float = 1.1


def send_all(reminders: Iterable[T], send: Callable[[T], object]) -> int:
    """Return the number of reminders sent, with 1.1 s between consecutive send calls."""
    if not callable(send):
        raise ValueError("send must be callable")
    if reminders is None:
        raise ValueError("reminders must be an iterable, not None")

    count = 0
    for reminder in reminders:
        if count:
            time.sleep(SEND_INTERVAL_SECONDS)
        send(reminder)
        count += 1
    return count
```

The pause happens only between calls, so there's no wasted wait after the last reminder. The wait starts after `send` returns, which means the starts of two calls are always at least 1.1 s apart, even when `send` is slow.
