```python
def format_invoice_number(year: int, seq: int) -> str:
    """Return the invoice number formatted as 'INV-YYYY-NNNN'."""
    if not 1000 <= year <= 9999:
        raise ValueError(f"year must be a four-digit year, got {year}")
    if seq < 1:
        raise ValueError(f"seq must be a positive integer, got {seq}")
    # Past 9999 the number just gets longer. It is never cut short, because two invoices sharing a number is worse than a wider field.
    return f"INV-{year}-{seq:04d}"
```

`format_invoice_number(2026, 42)` returns `'INV-2026-0042'`. It raises `ValueError` for a year that isn't four digits or a sequence number below 1.
