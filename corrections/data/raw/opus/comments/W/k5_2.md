```python
from datetime import date, datetime


def is_overdue(due: date, today: date) -> bool:
    """Return True if the due date is strictly before today."""
    # datetime is a subclass of date, so isinstance(x, date) alone lets it through.
    # Comparing a datetime to a date raises TypeError, so reject it here with a clear message.
    for name, value in (("due", due), ("today", today)):
        if not isinstance(value, date) or isinstance(value, datetime):
            raise ValueError(f"{name} must be a datetime.date, got {type(value).__name__}")
    # An invoice due today is still payable today, so it only becomes overdue tomorrow.
    return due < today
```

An invoice counts as overdue only once its due date has passed, so one due today returns False. A `datetime` passed instead of a plain `date` raises a ValueError rather than being silently truncated.
