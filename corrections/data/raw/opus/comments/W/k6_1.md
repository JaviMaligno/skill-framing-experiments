```python
def format_invoice_number(year: int, seq: int) -> str:
    """Return the invoice number in the form 'INV-YYYY-NNNN'."""
    if not 1000 <= year <= 9999:
        raise ValueError(f"year must be a four-digit year, got {year}")
    # Reject anything past 9999 rather than letting it widen to 5 digits.
    # The fixed width keeps invoice numbers sorting correctly as plain strings.
    if not 1 <= seq <= 9999:
        raise ValueError(f"seq must be between 1 and 9999, got {seq}")
    return f"INV-{year}-{seq:04d}"
```

`format_invoice_number(2026, 42)` returns `'INV-2026-0042'`. If a year can have more than 9,999 invoices, the sequence width needs to grow, and that change has to be agreed with whatever parses or sorts these numbers.
