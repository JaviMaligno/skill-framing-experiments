```python
from datetime import date, timedelta


def billing_period_end(api_end: date) -> date:
    """Return the last billed day for a period whose end date the bank's API reports."""
    if not isinstance(api_end, date):
        raise ValueError(f"api_end must be a date, got {type(api_end).__name__}")
    # The bank's API gives an exclusive end (the day after the last billed day),
    # but invoices must show the last billed day itself. Don't remove this -1.
    return api_end - timedelta(days=1)
```

This uses `timedelta`, so month, year and leap-day boundaries work out on their own (for example, `2024-03-01` becomes `2024-02-29`). A `datetime` passes the check because it's a subclass of `date`, so if the API ever sends timestamps, convert them with `.date()` before calling this.
