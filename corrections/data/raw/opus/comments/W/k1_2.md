```python
from datetime import date, timedelta


def billing_period_end(api_end: date) -> date:
    """Return the last billed day for a period end date reported by the bank's API."""
    if not isinstance(api_end, date):
        raise ValueError(f"api_end must be a date, got {type(api_end).__name__}")
    if api_end == date.min:
        raise ValueError("api_end cannot be date.min; there is no earlier day to bill")
    # The bank reports period ends as exclusive (the day after the last billed day),
    # but invoices must show the last billed day, so shift back by one.
    return api_end - timedelta(days=1)
```

If you pass a `datetime`, the function still returns a `datetime`, because `datetime` is a subclass of `date`. If you only want plain dates, add a check that rejects `datetime` values.
