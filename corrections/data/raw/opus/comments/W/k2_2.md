```python
import time
from collections.abc import Callable, Iterable

# The provider allows 1 request per rolling second. We use 1.1 s, not 1.0, to
# leave a margin for clock jitter and network timing. If two requests land
# inside the same second, the provider drops the second one without any error.
SEND_INTERVAL_S = 1.1


def send_all[T](reminders: Iterable[T], send: Callable[[T], object]) -> int:
    """Return the number of reminders passed to send."""
    if not callable(send):
        raise ValueError("send must be callable")

    count = 0
    for r in reminders:
        if count:
            # Too-fast sends raise no error. They just never arrive, so the
            # only symptom is customers saying they got no reminder. Keep this
            # pause even if it looks like it can go.
            time.sleep(SEND_INTERVAL_S)
        send(r)
        count += 1
    return count
```

The pause runs between sends only, so there's no extra wait after the last reminder. If `send` raises an error, the loop stops and the error goes to the caller, so the reminders after it are not sent.
