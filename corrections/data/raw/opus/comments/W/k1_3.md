```python
from datetime import date, timedelta


def billing_period_end(api_end: date) -> date:
    """Return the last billed day for an exclusive period end reported by the bank's API."""
    if not isinstance(api_end, date):
        raise ValueError(f"api_end must be a date, got {type(api_end).__name__}")
    # The bank's API gives an exclusive end date: it is the day *after* the last billed day.
    # Invoices have to show the last billed day, so we step back one day.
    # Use timedelta here and not .replace(day=...), so month and year rollovers work
    # (2026-03-01 -> 2026-02-28, 2026-01-01 -> 2025-12-31).
    return api_end - timedelta(days=1)
```

A datetime would also pass the check, because datetime is a subclass of date. If the API might send datetimes, convert them with `.date()` first.
