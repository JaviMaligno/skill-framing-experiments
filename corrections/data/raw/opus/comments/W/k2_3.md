```python
import time
from collections.abc import Callable, Iterable
from typing import TypeVar

T = TypeVar("T")

# The provider allows one request per rolling second and silently drops extras,
# so a rate-limit breach shows up as missing emails, not as an error. The extra
# 0.1 s covers timer jitter and clock skew on their side.
SEND_INTERVAL_S = 1.1


def send_all(reminders: Iterable[T], send: Callable[[T], object]) -> None:
    """Return None after calling send on each reminder, at least SEND_INTERVAL_S apart."""
    if not callable(send):
        raise ValueError("send must be callable")

    for i, reminder in enumerate(reminders):
        if i:
            time.sleep(SEND_INTERVAL_S)
        send(reminder)
```

It only sleeps between calls, so a single reminder goes out right away and nothing waits after the last one. If `send` raises, the loop stops there and none of the later reminders are sent.
