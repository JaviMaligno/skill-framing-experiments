```python
from typing import Any


def dedupe_payments(payments: list[dict[str, Any]]) -> list[dict[str, Any]]:
    """Return one payment per ref, keeping the lowest-id record, sorted by id."""
    canonical: dict[Any, dict[str, Any]] = {}
    for payment in payments:
        if "id" not in payment or "ref" not in payment:
            raise ValueError(f"payment missing 'id' or 'ref': {payment!r}")
        ref = payment["ref"]
        current = canonical.get(ref)
        # Upstream sends duplicates out of order, so the first one we see for a ref
        # may not be canonical. Compare ids every time; don't keep the first seen.
        if current is None or payment["id"] < current["id"]:
            canonical[ref] = payment
    # The input order is whatever upstream happened to send, so sort by id to get the
    # same output on every run for the same set of payments.
    return sorted(canonical.values(), key=lambda p: p["id"])
```

If two records have the same ref and the same id, the function keeps the first one it saw. It also assumes all ids are the same comparable type, so a mix of ints and strings will raise a `TypeError` during the comparison.
