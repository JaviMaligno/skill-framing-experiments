```python
def format_invoice_number(year: int, seq: int) -> str:
    """Return the invoice number formatted as 'INV-YYYY-NNNN'."""
    if not 1000 <= year <= 9999:
        raise ValueError(f"year must be four digits, got {year}")
    if seq < 1:
        raise ValueError(f"seq must be positive, got {seq}")
    # Sequences past 9999 widen to five or more digits rather than wrapping, so numbers stay unique.
    return f"INV-{year}-{seq:04d}"
```

`format_invoice_number(2026, 42)` returns `'INV-2026-0042'`. If you'd rather reject sequences above 9999, add an upper bound to the `seq` check.
