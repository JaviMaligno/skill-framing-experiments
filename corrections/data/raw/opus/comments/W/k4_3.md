```python
from decimal import Decimal, ROUND_HALF_UP

_CENTS = Decimal("0.01")


def total_with_vat(net: Decimal, rate: Decimal) -> Decimal:
    """Return net plus VAT at `rate` (e.g. Decimal("0.21") for 21%), rounded to cents half up."""
    if not isinstance(net, Decimal) or not isinstance(rate, Decimal):
        # Floats would carry binary error into the total (0.1 isn't really 0.1),
        # so make the caller convert explicitly instead of hiding it here.
        raise ValueError("net and rate must be Decimal")
    if not net.is_finite() or not rate.is_finite():
        raise ValueError("net and rate must be finite")
    if net < 0:
        raise ValueError("net must be non-negative")
    if not 0 <= rate < 1:
        # Guards against someone passing 21 for 21%, which would bill 22x the net.
        raise ValueError("rate must be a fraction in [0, 1)")

    # Round once, on the final total only. Rounding the VAT separately and adding
    # it can be off by a cent from what invoices and tax filings expect.
    # Pass rounding= explicitly: the default context uses ROUND_HALF_EVEN.
    return (net * (1 + rate)).quantize(_CENTS, rounding=ROUND_HALF_UP)
```

`rate` is a fraction, so 21% is `Decimal("0.21")`. If your invoices round the VAT line on its own before adding it, tell me and I'll change it to round there.
