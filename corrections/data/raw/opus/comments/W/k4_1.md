```python
from decimal import Decimal, ROUND_HALF_UP

_CENTS = Decimal("0.01")


def total_with_vat(net: Decimal, rate: Decimal) -> Decimal:
    """Return net plus VAT at `rate`, rounded half up to 2 decimals."""
    if not net.is_finite() or not rate.is_finite():
        raise ValueError("net and rate must be finite")
    if net < 0:
        raise ValueError("net must be non-negative")
    if not 0 <= rate <= 1:
        # Catches callers who pass 21 meaning 21%. That would bill 22x the net with no error.
        raise ValueError("rate must be a fraction between 0 and 1, e.g. Decimal('0.21')")

    # Round once, on the total. If you round the VAT amount first and then add it,
    # some totals come out a cent off from what the invoice math says.
    # Python's default rounding is ROUND_HALF_EVEN, so pass HALF_UP explicitly.
    return (net * (1 + rate)).quantize(_CENTS, rounding=ROUND_HALF_UP)
```

The function expects `rate` as a fraction (`Decimal("0.21")`, not `21`). If the inputs come from floats, build them as `Decimal(str(x))` so float error doesn't change how a half-cent rounds.
