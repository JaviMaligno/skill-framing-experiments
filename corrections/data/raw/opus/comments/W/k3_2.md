```python
from collections.abc import Iterable
from typing import Any


def dedupe_payments(payments: Iterable[dict[str, Any]]) -> list[dict[str, Any]]:
    """Return one payment per ref: the one with the lowest id."""
    canonical: dict[Any, dict[str, Any]] = {}
    for payment in payments:
        if "id" not in payment or "ref" not in payment:
            raise ValueError(f"payment missing 'id' or 'ref': {payment!r}")
        ref = payment["ref"]
        current = canonical.get(ref)
        # Compare ids instead of keeping the first one we see. Upstream sends
        # duplicates out of order, so the first copy to arrive may not be the
        # canonical record.
        if current is None or payment["id"] < current["id"]:
            canonical[ref] = payment
    return list(canonical.values())
```

The output lists refs in the order each one first appears in the input, and each entry is that ref's lowest-id record. A payment missing `id` or `ref` raises `ValueError`, and so do ids of different types that can't be compared to each other.
