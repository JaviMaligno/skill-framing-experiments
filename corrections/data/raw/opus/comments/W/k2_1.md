```python
import time
from collections.abc import Callable, Iterable
from typing import TypeVar

T = TypeVar("T")

# The provider allows 1 request per rolling second and drops extras without
# returning an error, so going over the limit loses reminders silently.
# The extra 0.1 s covers clock jitter between us and the provider.
_SEND_INTERVAL_S = 1.1


def send_all(reminders: Iterable[T], send: Callable[[T], object]) -> None:
    """Returns None after calling send once per reminder, spaced to respect the rate limit."""
    if send is None or not callable(send):
        raise ValueError("send must be callable")

    last_sent: float | None = None
    for reminder in reminders:
        if last_sent is not None:
            # Measure from the previous send's start so a slow send() doesn't add
            # extra delay, and use monotonic so a wall-clock change can't make the
            # interval shorter.
            wait = _SEND_INTERVAL_S - (time.monotonic() - last_sent)
            if wait > 0:
                time.sleep(wait)
        last_sent = time.monotonic()
        send(reminder)
```

The wait is measured from the start of the previous call, so a slow `send()` doesn't add extra delay, and there's no sleep after the last reminder. If `send` raises an exception, it stops the batch. Wrap it in a try/except if one failed reminder shouldn't block the rest.
