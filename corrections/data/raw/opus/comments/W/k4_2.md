```python
from decimal import Decimal, ROUND_HALF_UP

_CENTS = Decimal("0.01")


def total_with_vat(net: Decimal, rate: Decimal) -> Decimal:
    """Return net plus VAT at the given rate, rounded to cents (half up)."""
    if not isinstance(net, Decimal) or not isinstance(rate, Decimal):
        raise ValueError("net and rate must be Decimal")
    if not net.is_finite() or not rate.is_finite():
        raise ValueError("net and rate must be finite")
    # rate is a fraction (0.21), not a percentage. A rate above 1 almost always
    # means someone passed 21 for 21%, which would bill 22x the net amount.
    if not Decimal(0) <= rate <= Decimal(1):
        raise ValueError(f"rate must be a fraction between 0 and 1, got {rate}")
    # Negative net is allowed on purpose: credit notes go through here too.
    total = net * (Decimal(1) + rate)
    # Set the rounding mode explicitly. Decimal defaults to ROUND_HALF_EVEN
    # (banker's rounding), which would turn 10.125 into 10.12 instead of 10.13.
    return total.quantize(_CENTS, rounding=ROUND_HALF_UP)
```

`rate` has to be a fraction like `Decimal("0.21")`, not `21`. Rounding happens once, on the final total, so you don't get the extra rounding error from rounding the VAT amount on its own first.
