```python
def format_invoice_number(year: int, seq: int) -> str:
    """Return the invoice number formatted as INV-<year>-<seq zero-padded to 4 digits>."""
    if not 1000 <= year <= 9999:
        raise ValueError(f"year must be a four-digit number, got {year}")
    if seq < 1:
        raise ValueError(f"seq must be a positive integer, got {seq}")
    return f"INV-{year}-{seq:04d}"
```

`format_invoice_number(2026, 42)` returns `'INV-2026-0042'`. If `seq` goes over 9999 the number just gets longer instead of being cut off, so `(2026, 12345)` gives `'INV-2026-12345'`.
