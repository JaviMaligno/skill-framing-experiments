```python
from datetime import date, datetime


def is_overdue(due: date, today: date) -> bool:
    """Return True if the due date is strictly before today."""
    for value in (due, today):
        # datetime subclasses date, but comparing a datetime with a plain date raises TypeError.
        if isinstance(value, datetime) or not isinstance(value, date):
            raise ValueError(f"expected a date, got {type(value).__name__}")
    return due < today
```

An invoice that's due today isn't overdue yet. It only becomes overdue the day after its due date.
