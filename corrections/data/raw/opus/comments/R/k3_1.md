```python
from typing import Any


def dedupe_payments(payments: list[dict[str, Any]]) -> list[dict[str, Any]]:
    """Return one payment per ref, keeping the record with the lowest id."""
    canonical: dict[Any, dict[str, Any]] = {}
    for payment in payments:
        if "id" not in payment or "ref" not in payment:
            raise ValueError(f"payment missing 'id' or 'ref': {payment!r}")
        ref = payment["ref"]
        # Upstream sends duplicates out of order, so arrival order can't pick the canonical
        # record. The lowest id is the canonical one.
        if ref not in canonical or payment["id"] < canonical[ref]["id"]:
            canonical[ref] = payment
    return list(canonical.values())
```

The results come back in the order each ref first appears in the input. If a payment is missing `id` or `ref`, the function raises `ValueError` and does not skip it.
