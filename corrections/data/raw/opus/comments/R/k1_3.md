```python
from datetime import date, timedelta


def billing_period_end(api_end: date) -> date:
    """Return the last billed day of the period."""
    if not isinstance(api_end, date):
        raise ValueError(f"api_end must be a date, got {type(api_end).__name__}")
    # The bank's API reports period ends as exclusive (the day after the last billed day).
    return api_end - timedelta(days=1)
```

This function takes one day off the bank's exclusive end date, so the invoice shows the last day actually billed. It also rejects anything that isn't a `date` with a `ValueError`. Because `datetime` is a subclass of `date`, a `datetime` passes the check and comes back as a `datetime`, not a plain `date`.
