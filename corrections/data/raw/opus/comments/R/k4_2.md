```python
from decimal import Decimal, ROUND_HALF_UP

CENT = Decimal("0.01")


def total_with_vat(net: Decimal, rate: Decimal) -> Decimal:
    """Return the gross amount (net plus VAT at the given fractional rate), rounded to cents half up."""
    if not net.is_finite() or not rate.is_finite():
        raise ValueError("net and rate must be finite numbers")
    if net < 0:
        raise ValueError(f"net must be non-negative, got {net}")
    if not 0 <= rate <= 1:
        raise ValueError(f"rate must be a fraction between 0 and 1, got {rate}")

    # Round once, on the total. Rounding the VAT on its own first can be off by a cent.
    return (net * (1 + rate)).quantize(CENT, rounding=ROUND_HALF_UP)
```

The function expects `rate` as a fraction (for example `Decimal("0.21")` for 21%), so a percentage like `21` raises `ValueError` instead of producing a total 22 times the net.
