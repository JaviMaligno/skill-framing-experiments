```python
import time
from collections.abc import Callable, Iterable
from typing import TypeVar

T = TypeVar("T")

# The provider allows one request per rolling second and silently drops extras;
# 1.1 s leaves margin for clock jitter.
SEND_INTERVAL_SECONDS = 1.1


def send_all(reminders: Iterable[T], send: Callable[[T], object]) -> int:
    """Return the number of reminders passed to send."""
    if not callable(send):
        raise ValueError("send must be callable")

    count = 0
    for reminder in reminders:
        if count:
            time.sleep(SEND_INTERVAL_SECONDS)
        send(reminder)
        count += 1
    return count
```

The function only waits between calls, so a single reminder goes out right away and nothing sleeps after the last one. Uncaught exceptions from `send` stop the loop, so a failed send isn't skipped without anyone noticing.
