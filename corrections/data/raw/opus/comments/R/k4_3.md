```python
from decimal import Decimal, ROUND_HALF_UP

CENT = Decimal("0.01")


def total_with_vat(net: Decimal, rate: Decimal) -> Decimal:
    """Return the net amount plus VAT, rounded to 2 decimals half up."""
    if not isinstance(net, Decimal) or not isinstance(rate, Decimal):
        raise ValueError("net and rate must be Decimal")
    if not net.is_finite() or not rate.is_finite():
        raise ValueError("net and rate must be finite")
    if net < 0:
        raise ValueError("net must not be negative")
    if not Decimal(0) <= rate <= Decimal(1):
        raise ValueError("rate must be a fraction between 0 and 1, e.g. Decimal('0.21')")
    # Round once on the final total so the VAT line can't add a second rounding error.
    return (net * (1 + rate)).quantize(CENT, rounding=ROUND_HALF_UP)
```

`rate` is a fraction, so 21% is `Decimal("0.21")`. If you want it as a percentage like `Decimal("21")`, I can switch it to divide by 100 instead.
