```python
from datetime import date


def is_overdue(due: date, today: date) -> bool:
    """Return True if the due date is strictly before today."""
    if not isinstance(due, date) or not isinstance(today, date):
        raise ValueError("due and today must be date objects")
    return due < today
```

An invoice that falls due today doesn't count as overdue until tomorrow. A `datetime` passes the type check because it's a subclass of `date`, so callers should pass plain dates.
