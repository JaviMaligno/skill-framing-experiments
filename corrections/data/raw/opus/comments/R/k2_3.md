```python
import time
from collections.abc import Callable, Iterable
from typing import TypeVar

T = TypeVar("T")

# The email provider allows one request per rolling second and silently drops extras;
# 1.1 s leaves margin for clock jitter.
SEND_INTERVAL_S = 1.1


def send_all(reminders: Iterable[T], send: Callable[[T], object]) -> int:
    """Return the number of reminders passed to send."""
    if not callable(send):
        raise ValueError("send must be callable")

    count = 0
    for reminder in reminders:
        if count:
            time.sleep(SEND_INTERVAL_S)
        send(reminder)
        count += 1
    return count
```

The 1.1 s wait happens only between calls, so there's no extra delay before the first send or after the last one. If `send` raises an exception, the loop stops and the exception reaches the caller.
