```python
def format_invoice_number(year: int, seq: int) -> str:
    """Return the invoice number for a year and sequence, e.g. 'INV-2026-0042'."""
    if not 1000 <= year <= 9999:
        raise ValueError(f"year must be a four-digit year, got {year}")
    if not 1 <= seq <= 9999:
        raise ValueError(f"seq must be between 1 and 9999, got {seq}")
    return f"INV-{year}-{seq:04d}"
```

A `seq` above 9999 raises `ValueError`, so invoice numbers always keep the fixed four-digit format. If you need more than 9,999 invoices in a year, remove that upper bound and numbers above 9999 will print with more digits.
