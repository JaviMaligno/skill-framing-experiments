```python
from decimal import Decimal, ROUND_HALF_UP

_CENT = Decimal("0.01")


def total_with_vat(net: Decimal, rate: Decimal) -> Decimal:
    """Return the net amount plus VAT, rounded to 2 decimals half up."""
    if not net.is_finite() or not rate.is_finite():
        raise ValueError("net and rate must be finite decimals")
    if net < 0:
        raise ValueError(f"net must be non-negative, got {net}")
    if not 0 <= rate <= 1:
        raise ValueError(f"rate must be a fraction between 0 and 1, got {rate}")

    # Round once at the end so the result doesn't drift by a cent from early rounding.
    return (net * (1 + rate)).quantize(_CENT, rounding=ROUND_HALF_UP)
```

`rate` is a fraction, so 21% is `Decimal("0.21")`. Passing `21` raises a `ValueError` instead of returning a total 22 times too large.
