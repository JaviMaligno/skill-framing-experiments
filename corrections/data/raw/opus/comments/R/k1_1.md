```python
from datetime import date, timedelta


def billing_period_end(api_end: date) -> date:
    """Return the last billed day for a period whose API end date is exclusive."""
    if not isinstance(api_end, date):
        raise ValueError(f"api_end must be a date, got {type(api_end).__name__}")
    # The bank's API gives the day after the last billed day, so step back one day.
    return api_end - timedelta(days=1)
```

The function takes a day off the bank's exclusive end date, so the invoice shows the last day that was actually billed. A `datetime` is also accepted because it's a subclass of `date`. If you want only plain dates, add an explicit `isinstance(api_end, datetime)` check that rejects it.
