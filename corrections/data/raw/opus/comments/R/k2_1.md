```python
import time
from collections.abc import Callable, Iterable
from typing import TypeVar

T = TypeVar("T")

SEND_INTERVAL_SECONDS = 1.1


def send_all(reminders: Iterable[T], send: Callable[[T], object]) -> int:
    """Return the number of reminders passed to send, one at a time."""
    if not callable(send):
        raise ValueError("send must be callable")

    count = 0
    for reminder in reminders:
        if count:
            # The email provider allows one request per rolling second and silently
            # drops any extra, so keep a margin above 1 s between calls.
            time.sleep(SEND_INTERVAL_SECONDS)
        send(reminder)
        count += 1
    return count
```

The function waits only between calls, so it doesn't pause after the last reminder. It returns how many reminders it sent, and if `send` raises an error, the loop stops right away.
