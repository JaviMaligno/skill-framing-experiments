```python
from datetime import date, timedelta


def billing_period_end(api_end: date) -> date:
    """Return the last billed day for a period end date reported by the bank's API."""
    if not isinstance(api_end, date):
        raise ValueError(f"api_end must be a date, got {type(api_end).__name__}")
    # The bank's API reports period ends as exclusive (the day after the last billed day).
    return api_end - timedelta(days=1)
```

The function subtracts one day, so month and year boundaries are handled correctly; for example, an API end of 2026-03-01 becomes 2026-02-28. The type check rejects a missing or non-date value with ValueError, but a `datetime` still gets through because `datetime` is a subclass of `date`.
