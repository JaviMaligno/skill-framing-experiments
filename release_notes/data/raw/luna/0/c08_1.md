## What’s new

- **Zapier:** Added an **Invoice overdue** trigger to help automate follow-ups.
- **Payment QR codes:** Invoices can now include an EPC QR code (Girocode) for easier payments.

## Fixes and improvements

- Fixed PDF generation timeouts on large invoices (100+ lines) caused by a memory leak.
- Fixed **Duplicate invoice** copying the original due date.
- Converted the remaining class components to hooks.
- Added Playwright end-to-end tests for onboarding.
