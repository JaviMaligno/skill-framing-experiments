## What’s new in Ledgerly

- **SEPA Direct Debit via GoCardless:** Set up direct debit payments in **Settings → Payments**.
- **Fresher converted totals:** Exchange rates now refresh every hour instead of every 24 hours.

## Fixes and improvements

- Fixed the Send button crashing when a client had no email address.
- Fixed the date picker so weeks start on Monday for UK users.
- Renamed the database column `amount_cents` to `amount_minor`.
- Added Storybook stories for the Button component.
