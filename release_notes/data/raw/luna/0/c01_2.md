## This week in Ledgerly

- **API key expiration:** New API keys now expire after 90 days. Existing keys without an expiry will be revoked on **November 15, 2026**. (FAC-1182, #4410)
- **Faster Clients page:** Fixed an N+1 query that could make the page take up to 8 seconds to load for accounts with more than 500 clients.
- **Checkout diagnostics:** Added Sentry breadcrumbs to the checkout flow to improve troubleshooting.
- **Invoice rendering:** Updated InvoiceRenderer to use pdfkit 0.15.
- **Developer tooling:** Upgraded ESLint to 9.12.
- **UI fix:** The Due date tooltip no longer overlaps the Status filter.
