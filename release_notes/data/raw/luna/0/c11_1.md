## Ledgerly release notes

This update strengthens account security, adds a new sign-in option, and fixes several issues.

- **Stronger password protection:** New passwords must be at least 12 characters. Starting **November 20, 2026**, users with shorter passwords will be prompted to change them at their next login.
- **Improved password security:** Passwords are now hashed with Argon2id instead of bcrypt.
- **Microsoft sign-in:** Sign in to Ledgerly using your Microsoft account.
- **Invoice drafts preserved:** Fixed an issue where an expired session could silently cause unsaved invoice drafts to be lost.
- **German Settings translation:** Restored the missing German translation on the Settings page.
- **Under the hood:** Updated TypeScript to 5.7.
