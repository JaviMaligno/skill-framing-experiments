## Ledgerly updates

- **Higher API limits:** The public API now allows up to 300 requests per minute, up from 60.
- **Filter profit & loss reports by client:** Focus reports on the clients you need.
- **Upload iPhone receipts:** Expense receipts in HEIC format are now supported.
- **Pagination fix:** The 51st invoice now appears as expected.
- **Storage improvements:** Image storage has moved from S3 to R2.
- **Cleanup:** Removed feature flags for the old onboarding flow.
