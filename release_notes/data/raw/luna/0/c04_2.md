## Ledgerly — This Week’s Update

### New
- Recurring invoices can now be set to bill on the last day of each month.
- Added OpenTelemetry tracing to the API gateway.

### Improved
- Reminder emails are now protected against duplicate sends when “Send reminder” is clicked repeatedly.
- SVG logo uploads now work for files larger than 1 MB.

### Deprecation
- Legacy XLS export is deprecated and will be removed on **December 1, 2026**. Use **XLSX** or **CSV** instead.
