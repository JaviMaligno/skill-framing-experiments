# Ledgerly Release Notes

- **API key security:** New API keys expire after 90 days. Existing keys without an expiry will be revoked on **November 15, 2026**. *(FAC-1182, #4410)*
- **Faster Clients page:** Fixed a slow query affecting accounts with more than 500 clients.
- **Improved checkout diagnostics:** Added Sentry breadcrumbs to the checkout flow.
- **Invoice rendering:** Updated InvoiceRenderer to use pdfkit 0.15.
- **UI fix:** The Due date tooltip no longer overlaps the Status filter.
- **Developer tooling:** Updated ESLint to 9.12.
