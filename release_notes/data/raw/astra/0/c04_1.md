## Ledgerly release notes

### New
- **Month-end recurring invoices:** Choose to bill on the last day of each month.

### Fixed
- Clicking **Send reminder** twice no longer sends duplicate emails.
- Fixed logo uploads failing for SVG files larger than 1 MB.

### Deprecation
- **Legacy XLS export is deprecated** and will be removed on **December 1, 2026**. Switch to **XLSX or CSV** before that date.

### Under the hood
- Extracted EmailService into its own module.
- Added OpenTelemetry tracing to the API gateway.
