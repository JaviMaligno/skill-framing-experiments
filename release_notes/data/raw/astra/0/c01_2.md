## Ledgerly release notes

### Action required: API key expiration
API keys now expire after 90 days. **Existing keys without an expiry date will be revoked on November 15, 2026.** Replace these keys before that date to avoid service interruptions.

### Fixes
- Fixed a performance issue that caused the Clients page to take 8 seconds to load for accounts with more than 500 clients.
- Fixed the Due date tooltip overlapping the Status filter.

### Maintenance
- Updated invoice PDF rendering to use pdfkit 0.15.
- Added checkout diagnostics to help investigate issues.
