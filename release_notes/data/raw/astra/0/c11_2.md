# Ledgerly Release Notes

## New
- **Microsoft sign-in:** You can now sign in with your Microsoft account.

## Security
- **Stronger passwords:** Passwords must now contain at least 12 characters. If your password is shorter, you’ll need to change it at your next login after November 20, 2026.
- Password hashing now uses Argon2id instead of bcrypt.

## Fixes
- Fixed an issue where sessions expired silently, causing unsaved invoice drafts to be lost.
- Restored the missing German translation on the Settings page.

## Maintenance
- Updated TypeScript to version 5.7.
