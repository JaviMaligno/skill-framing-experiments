## Ledgerly release notes

### New
- **Month-end recurring invoices:** Schedule recurring invoices to bill on the last day of each month.

### Fixed
- Clicking **Send reminder** twice no longer sends duplicate emails.
- Fixed logo uploads failing for SVG files larger than 1 MB.

### Deprecation notice
- **Legacy XLS export is deprecated** and will be removed on **December 1, 2026**. Switch to **XLSX or CSV** before then.

### Under the hood
- Extracted EmailService into a standalone module.
- Added OpenTelemetry tracing to the API gateway.
