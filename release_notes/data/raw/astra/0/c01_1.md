## Ledgerly release notes

### Security
- API keys now expire after 90 days. **Existing keys without an expiry will be revoked on November 15, 2026.** Replace these keys before that date to avoid interruptions to your integrations.

### Fixes
- Fixed a performance issue that caused the Clients page to take 8 seconds to load for accounts with more than 500 clients.
- Fixed the Due date column tooltip overlapping the Status filter.

### Behind the scenes
- Updated invoice PDF rendering to use pdfkit 0.15.
- Added checkout diagnostics to help troubleshoot issues.
- Updated ESLint to 9.12.
