## What’s new in Ledgerly

- **Profit & loss by client:** Filter your report by client to see how each one contributes to your bottom line.
- **Upload iPhone receipts:** Expense receipts in HEIC format now upload successfully.
- **Every invoice shows up:** The 51st invoice no longer goes missing when you page through your list.
- **More room for API requests:** The Public API limit is now 300 requests per minute, up from 60.
