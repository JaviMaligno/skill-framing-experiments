## What’s new in Ledgerly

- Add an extra layer of protection with two-factor authentication using an authenticator app. Set it up in **Settings → Security**.
- CSV exports now include the **Paid on** column, so you can see when invoices were paid.
- Autosave no longer loses edits when you have two tabs open.
- Spanish invoice footers now correctly say “Factura” instead of “Fatura”.
