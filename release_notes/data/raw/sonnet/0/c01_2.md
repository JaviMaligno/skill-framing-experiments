# Ledgerly Release Notes

## Security

- **API keys now expire after 90 days.** Newly created keys expire automatically, so you'll want to rotate them regularly. **Action required:** existing API keys that have no expiry date will be revoked on **November 15, 2026**. Before then, generate new keys and update any integrations that rely on the old ones. (FAC-1182, #4410)

## Improvements

- **Faster Clients page.** We fixed a performance issue that made the Clients page take around 8 seconds to load for accounts with more than 500 clients.

## Fixes

- Fixed a tooltip on the Due date column that overlapped the Status filter.

## Under the hood

- Updated invoice PDF generation to use pdfkit 0.15.
- Added more diagnostic tracking to the checkout flow to help us spot and resolve issues faster.
- Updated internal tooling (eslint 9.12).
