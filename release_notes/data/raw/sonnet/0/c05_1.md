# Ledgerly Release Notes

## New
- **SEPA Direct Debit payments.** You can now collect payments via SEPA Direct Debit, powered by GoCardless. Enable it under **Settings → Payments**.

## Improved
- **Fresher converted totals.** Exchange rates are now cached for 1 hour instead of 24, so totals converted between currencies reflect more recent rates.

## Fixed
- **Send button crash.** Fixed a crash that occurred when you clicked Send for a client with no email address on file.
- **Date picker for UK users.** Weeks in the date picker now start on Monday for UK users, instead of Sunday.
