# Ledgerly Release Notes

## New

**Multi-currency invoicing**
You can now invoice in one currency and get paid in another. The conversion is shown on the PDF, so both you and your client can see exactly what was billed and what was received.

**Archive clients instead of deleting them**
Clients can now be archived rather than deleted. Archived clients are hidden from your client lists, which keeps things tidy without losing any history.

## Fixes

- **CSV import:** Files that use semicolon delimiters, which are common in Spain and Germany, now import correctly instead of failing.
- **Email preview:** The preview no longer shows a raw `{{client_name}}` placeholder. It now shows the client's actual name.

## Under the hood

- Faster loading of client data, thanks to batched GraphQL client resolution with DataLoader.
- Removed about 40 KB of unused CSS for a lighter app.
