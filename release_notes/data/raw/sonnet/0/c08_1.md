# Ledgerly Release Notes

## New

- **Payment QR codes on invoices.** Invoices can now include an EPC QR code (Girocode), so customers can pay by scanning it with their banking app.
- **Zapier: new "Invoice overdue" trigger.** Start automations in Zapier when an invoice goes overdue, for example to send reminders or notify your team.

## Fixes

- **Large invoices no longer time out.** We fixed a memory leak in PDF generation that caused invoices with 100 or more lines to time out.
- **"Duplicate invoice" now uses the right due date.** Duplicated invoices no longer copy the original due date.
