# Ledgerly Release Notes

## Improvements

- **Higher API rate limit:** The public API rate limit has increased from 60 to 300 requests per minute, giving your integrations much more headroom (LED-120).
- **Profit & loss by client:** You can now filter profit & loss reports by client.
- **Faster, more reliable image storage:** Images are now stored on Cloudflare R2 instead of Amazon S3. No action is needed on your side.

## Bug fixes

- Fixed an issue where expense receipts in HEIC format, the default for iPhone photos, couldn't be uploaded.
- Fixed a pagination error that hid the 51st invoice in lists.
