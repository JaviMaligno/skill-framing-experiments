# Ledgerly Release Notes

## New

**Multi-currency invoicing**
You can now invoice in one currency and get paid in another. The conversion is shown on the PDF, so you and your clients can see exactly how amounts were calculated.

**Archive clients**
Clients can now be archived instead of deleted. Archived clients are hidden from your client lists, which keeps them tidy without losing any history.

## Fixes

- **CSV import:** Files that use semicolon delimiters, which are common in Spain and Germany, now import correctly.
- **Email preview:** The preview no longer shows a raw `{{client_name}}` placeholder. It now shows the client's actual name.

## Under the hood

- Improved performance when loading client data.
- Removed unused CSS (40 KB smaller), which helps pages load faster.
