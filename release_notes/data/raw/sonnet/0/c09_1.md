# Ledgerly Release Notes

## New
- **Profit & loss by client:** You can now filter profit & loss reports by client.
- **Higher API rate limit:** The public API rate limit has gone up from 60 to 300 requests per minute (LED-120).

## Fixed
- **HEIC receipts:** Expense receipts in HEIC format, such as iPhone photos, can now be uploaded.
- **Missing invoice:** An off-by-one error in pagination was hiding the 51st invoice. It now appears.

## Under the hood
- Image storage has moved from S3 to R2.
- We removed the old onboarding feature flags.
