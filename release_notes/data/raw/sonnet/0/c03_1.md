# Ledgerly Release Notes

## New
- **Dark mode for the dashboard.** Switch themes anytime under Settings → Appearance.
- **New `invoice.paid` webhook event.** Get notified the moment an invoice is paid (LED-77).

## Fixed
- **PDF invoice totals in German locale.** Invoices generated with the de-DE locale no longer round totals to whole euros; cents are now shown correctly.

## Improved
- **Stripe webhook delivery logging.** Retry attempts for failed Stripe webhook deliveries are now logged, making delivery issues easier to diagnose.

## Under the hood
- Replaced moment.js with date-fns.
- Upgraded CI runners to ubuntu-24.04.
