# Ledgerly Release Notes

## New

- **Bill recurring invoices on the last day of the month.** Recurring invoices now have an option to bill on the last day of each month, so billing dates stay consistent in months of different lengths.

## Fixed

- **Duplicate payment reminders.** Clicking "Send reminder" twice no longer sends two emails.
- **SVG logo uploads.** Uploading an SVG logo larger than 1MB no longer fails.

## Deprecations

- **Legacy XLS export is being retired.** XLS export will be removed on **December 1, 2026**. Please switch to XLSX or CSV before then.

## Under the hood

- Added OpenTelemetry tracing to the API gateway for better observability.
- Extracted EmailService into its own module.
