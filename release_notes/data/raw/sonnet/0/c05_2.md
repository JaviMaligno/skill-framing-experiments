# Ledgerly Release Notes

## New
- **SEPA Direct Debit:** You can now collect payments by SEPA Direct Debit through GoCardless. Enable it under **Settings → Payments**.

## Improved
- **Fresher currency conversions:** Exchange rates are now cached for 1 hour instead of 24, so converted totals reflect more recent rates.

## Fixed
- **Send button crash:** Fixed a crash when sending an invoice to a client with no email address on file.
- **Date picker for UK users:** Weeks now start on Monday, as expected, instead of Sunday.
