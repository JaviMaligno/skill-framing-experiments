# Ledgerly Release Notes

## New

- **Payment QR codes on invoices.** Invoices can now include an EPC QR code (Girocode), so customers can scan it with their banking app to pay with the amount and details already filled in.
- **Zapier: new "Invoice overdue" trigger.** Start a Zap automatically when an invoice goes overdue, for example to send a reminder or notify your team.

## Fixes

- **Large invoices no longer time out.** We fixed a memory leak in PDF generation that made invoices with 100 or more lines fail to generate.
- **Duplicated invoices now get a fresh due date.** The "Duplicate invoice" button was copying the original's due date. It now sets the due date correctly.

## Under the hood

- Migrated the remaining class components to hooks.
- Added end-to-end onboarding tests with Playwright.
