# Ledgerly Release Notes

## New

- **Sign in with Microsoft.** You can now sign in to Ledgerly with your Microsoft account using OAuth.

## Security

- **Stronger password requirements.** Passwords must now be at least 12 characters long. If your current password is shorter, you'll be asked to change it the next time you sign in after November 20, 2026.
- **Improved password storage.** Passwords are now hashed with argon2id instead of bcrypt.

## Fixes

- Fixed an issue where your session could expire silently and cause unsaved invoice drafts to be lost.
- Fixed a missing German translation on the Settings page.

## Under the hood

- Updated TypeScript to version 5.7.
