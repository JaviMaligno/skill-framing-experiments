# Ledgerly Release Notes

## Security

**API keys now expire after 90 days.** For better account security, all new API keys expire 90 days after creation. Existing API keys that have no expiry date will be revoked on **November 15, 2026**. Before then, create new keys and update any integrations that rely on the old ones so they don't stop working.

## Improvements

- **Faster Clients page.** We fixed a performance issue that caused the Clients page to take around 8 seconds to load for accounts with more than 500 clients.
- **Updated invoice PDF generation.** We upgraded the engine that renders invoice PDFs to a newer version.

## Fixes

- Fixed a tooltip on the Due date column that overlapped the Status filter.
