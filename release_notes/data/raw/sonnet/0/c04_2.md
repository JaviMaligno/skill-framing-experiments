# Ledgerly Release Notes

## New
- **Bill recurring invoices on the last day of the month.** Recurring invoices now have an option to bill on the last day of each month, so billing lands correctly regardless of month length.

## Fixed
- **Duplicate reminder emails.** Clicking "Send reminder" twice no longer sends two emails.
- **SVG logo uploads.** Uploading an SVG logo larger than 1MB now works.

## Deprecation notice
- **XLS export will be removed on December 1, 2026.** Switch to XLSX or CSV before then.
