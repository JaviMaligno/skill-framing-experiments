# Ledgerly Release Notes

## New

- **Dark mode for the dashboard.** You can now switch the dashboard to a dark theme under **Settings → Appearance**.
- **New `invoice.paid` webhook event.** Subscribe to `invoice.paid` to be notified when an invoice is paid (LED-77).

## Fixed

- **PDF invoice totals in German locale.** Invoices generated with the `de-DE` locale no longer round totals to whole euros. They now show the exact amount.

## Improved

- **Better visibility into Stripe webhook delivery.** Retry attempts for failed Stripe webhook deliveries are now logged, which makes delivery problems easier to diagnose.

## Under the hood

- Replaced moment.js with date-fns.
- Upgraded CI runners to ubuntu-24.04.
