## Release notes

- **Receipts from iPhone photos now upload.** Expense receipts in HEIC format no longer fail to upload.
- **Filter profit & loss by client.** Reports now let you view profit & loss for a single client.
- **Higher API limit.** The public API now allows 300 requests per minute, up from 60.
- **Fixed:** The 51st invoice was missing from your invoice list. It now shows up.
