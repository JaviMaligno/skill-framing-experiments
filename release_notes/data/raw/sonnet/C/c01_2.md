## Ledgerly release notes

- **Action required by 15 November 2026:** API keys now expire after 90 days. Any existing API keys that have no expiry date will be revoked on 15 November 2026, so create new keys and update anything that uses them before then.
- The Clients page now loads much faster for accounts with more than 500 clients (it used to take around 8 seconds).
- Fixed the tooltip on the Due date column overlapping the Status filter.
