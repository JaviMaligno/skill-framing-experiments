## Release notes

**Action required: replace your API keys before November 15, 2026.** API keys without an expiry date will stop working on that day. Create a new key in your settings and update any tools that use the old one.

- API keys now expire after 90 days.
- The Clients page loads much faster if you have a large number of clients (it could take around 8 seconds before).
- Fixed the tooltip on the Due date column covering the Status filter.
