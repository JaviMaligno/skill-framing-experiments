## Ledgerly update

- **Faster API access:** The public API now allows up to 300 requests per minute, up from 60.
- **Receipts from your iPhone:** You can now upload expense receipts in HEIC format, so iPhone photos work as they are.
- **Profit & loss by client:** Reports now let you filter profit & loss by client.
- **Fixes:** Your 51st invoice no longer goes missing from the invoice list.
