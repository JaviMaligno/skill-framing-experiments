## Ledgerly release notes

### What's new
- **Dark mode for the dashboard.** Turn it on under Settings → Appearance.
- **New `invoice.paid` webhook event.** You can now get notified the moment an invoice is paid.

### What's fixed
- **PDF invoice totals in German format.** With the language set to German (de-DE), PDF invoices no longer round totals to whole euros. Cents now show up correctly.
