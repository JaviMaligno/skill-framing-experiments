## Release notes

**Action needed: nothing.** Everything below is already live.

### What's new
- **Profit & loss by client.** You can now filter your Profit & loss report by client, so you can see what each one is really worth to you.
- **Faster API.** If you use the Ledgerly API, the limit is now 300 requests per minute, up from 60.

### What's fixed
- **iPhone receipt photos upload.** Expense receipts taken on an iPhone (HEIC format) now upload without a problem.
- **Your 51st invoice is back.** It was missing from your invoice list, and now it shows up.
