**Release notes**

## Faster API, a client filter for reports, and two fixes

- **Higher API limit.** The public API now allows 300 requests per minute, up from 60.
- **Profit & loss by client.** You can now filter the profit & loss report by client.
- **iPhone receipts upload.** Expense receipts taken as HEIC photos on an iPhone now upload without errors.
- **Missing invoice.** The 51st invoice in your list no longer goes missing.
