# Ledgerly update: what's new this week

**Nothing you have to do.** Everything below is live when you log in.

## What's new

- **Payment QR codes on invoices.** Invoices now show a scannable code that opens your client's banking app with the amount and reference filled in. It uses the EPC QR (Girocode) standard.
- **Zapier: "Invoice overdue" trigger.** Zapier can now start a workflow the moment an invoice goes past its due date, so you can automatically send a reminder or log it in another app.

## What's fixed

- **Large invoices generate again.** Invoices with 100 lines or more were timing out when creating the PDF. That's fixed, and they should export without a wait.
- **Duplicating an invoice keeps the new due date.** "Duplicate invoice" used to copy the old due date. It now starts fresh, so check the date before you send.

A few smaller changes: we've tidied up parts of the app behind the scenes, and onboarding is now tested more thoroughly, so it should run smoothly for new accounts.
