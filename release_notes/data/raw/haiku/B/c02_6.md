## What's new in Ledgerly

- **Two-factor sign-in.** Add a second step to logging in, using a code from an authenticator app. Turn it on under Settings → Security.
- **CSV exports now include a "Paid on" column,** so you can see when each invoice was paid without opening it.
- **Edits no longer disappear when you have two tabs open.** Autosave now keeps what you typed, even if the same invoice is open in more than one tab.
- **Spanish invoice footers now say "Factura"** instead of "Fatura".
