**Ledgerly release notes: October 19, 2026**

## What's new
- **Profit & loss by client:** Filter the profit & loss report to see one client at a time.
- **Higher API limit:** Developers can now make 300 API requests a minute, up from 60.

## Fixes
- **iPhone photos as receipts:** HEIC photos from your iPhone now upload as expense receipts.
- **Invoice list:** Paging through invoices no longer skips the 51st one.
