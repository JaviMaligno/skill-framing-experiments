## Action needed by 15 November 2026

API keys now expire after 90 days. Any API key that has no expiry date will be revoked on **15 November 2026**. If an integration uses one of your keys, create a new key and swap it in before that date.

## What's new and fixed

- **Clients page loads much faster.** Accounts with more than 500 clients were waiting around 8 seconds. Now it opens straight away.
- **API keys have an expiry date.** New keys stop working after 90 days, so old ones don't stick around.
- **Due date tooltip no longer covers the Status filter.**
