## Action needed by 15 November 2026: API keys now expire

API keys now expire after 90 days. Keys created before this update have no expiry date, and they will stop working on **15 November 2026**. If an integration or script uses one, create a new key and swap it in before then.

## What's better

- **Clients page loads much faster.** For accounts with more than 500 clients, it used to take around 8 seconds to open. It now opens right away.
- **Due date tooltip no longer covers the Status filter.** Hovering over the Due date column is clean again.
