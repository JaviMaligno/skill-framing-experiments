## What's new in Ledgerly: October 19, 2026

**Two-factor authentication is here.** Turn it on under Settings → Security to add a second step when you log in, using an authenticator app on your phone.

- **Your edits are safe with two tabs open.** Autosave no longer drops changes when you're working in more than one tab.
- **CSV exports now include a "Paid on" column,** so you can see when each invoice was paid.
- **Spanish invoice footers say "Factura" now,** not "Fatura."
