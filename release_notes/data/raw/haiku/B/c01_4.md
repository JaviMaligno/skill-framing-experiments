**Action needed before November 15, 2026:** API keys now expire 90 days after they're created. Any API key that has no expiry date will be revoked on November 15, 2026. If an integration uses one of those keys, create a new key in your settings and switch the integration over before then.

## What's new and fixed

- **API keys expire after 90 days.** Set a reminder to create a new key before the old one runs out.
- **Clients page loads faster.** Accounts with more than 500 clients were waiting about 8 seconds for the page; it now opens without the long wait.
- **Due date tooltip no longer covers the Status filter.** Hovering over the Due date column won't block the filter anymore.
