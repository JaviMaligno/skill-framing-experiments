# Ledgerly release notes

**Heads up: Ledgerly is moving from moment.js to date-fns in this update. If you use custom date formats in integrations, check them after you update.**

## What's new

- **Dark mode for your dashboard.** Turn it on under Settings → Appearance.
- **New `invoice.paid` webhook event.** Get notified the moment an invoice is paid, instead of checking back.
- **Better visibility into failed Stripe webhooks.** Retry attempts are now logged, so you can see what happened to a delivery that didn't go through.

## Fixes

- **PDF totals fixed for German locale.** Invoices with the de-DE setting now show exact amounts, not totals rounded to whole euros.

## Smaller changes

- Faster, more reliable builds behind the scenes (CI runners upgraded to Ubuntu 24.04).
- Date handling switched to date-fns; nothing should look different on screen.
