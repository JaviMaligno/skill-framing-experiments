## Ledgerly update: October 2026

**Action needed by November 15, 2026:** API keys now expire after 90 days. Any existing key that has no expiry date will be revoked on **November 15, 2026**. If you use an API key for an integration, create a new one in Settings before then and update your integration with it.

### What's new and fixed

- **API keys** now show an expiry date, so you can see when each one needs replacing.
- **Clients page** loads much faster for accounts with lots of clients. It used to take up to 8 seconds.
- **Due date tooltip** no longer overlaps the Status filter.
