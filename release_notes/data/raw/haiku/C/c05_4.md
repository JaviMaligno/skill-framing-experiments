## This week's updates

- **New: SEPA Direct Debit payments.** Accept SEPA Direct Debit payments through GoCardless. Set it up in Settings → Payments.
- **Fixed a crash on Send.** The app no longer crashes when you click Send for a client with no email address.
- **Fresher converted totals.** Exchange rates now update hourly instead of daily, so converted totals are more current.
- **Date picker fix for UK users.** Weeks now start on Monday instead of Sunday.
