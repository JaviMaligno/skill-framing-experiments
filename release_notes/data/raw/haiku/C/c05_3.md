# Release notes

**Action required:** None.

- **Get paid by bank debit in Europe:** Set up SEPA Direct Debit under Settings → Payments.
- **Fixed:** The Send button no longer crashes when a client has no email address.
- **Fixed:** The date picker now starts weeks on Monday for UK users.
- **Fresher currency totals:** Converted totals now update using exchange rates refreshed every hour instead of every 24 hours.
