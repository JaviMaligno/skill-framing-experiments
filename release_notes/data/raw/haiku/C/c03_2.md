I'm going to write these for freelancers using Ledgerly, not engineers, so I'm leaving out the CI runner upgrade, the moment.js to date-fns swap, and the Stripe retry logging, since none of those are visible to users.

**Ledgerly update**

- **Dark mode:** Turn it on under Settings → Appearance to switch the dashboard to a dark theme.
- **PDF totals fixed:** Invoice PDFs showed totals rounded to whole euros when your locale was German (de-DE). Totals now show their full amounts.
- **New webhook event:** Webhooks can now send an `invoice.paid` event when an invoice is paid, so your other tools can react to payments as they happen.
