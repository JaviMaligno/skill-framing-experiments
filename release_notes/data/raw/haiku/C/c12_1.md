# Ledgerly release notes

## What's new
- **Multi-currency invoicing:** Invoice a client in one currency and get paid in another. The PDF shows the converted amount.
- **Archive clients:** Archiving a client hides them from your lists. Your records stay intact, so you no longer lose history by deleting.

## Fixes
- **CSV import:** Files with semicolons as separators (common in Spain and Germany) now import correctly.
- **Email preview:** The preview now shows the client's name instead of a `{{client_name}}` placeholder.

## Improvements
- Faster loading across the app.
- Lighter pages, so they load more quickly.
