Ledgerly update

**Action needed**
- Two-factor sign-in is now available. You can turn it on under Settings → Security.

**What's new**
- CSV exports now include a Paid on column, so you can see when each invoice was paid.

**Fixes**
- Autosave no longer loses edits when you have two tabs open at the same time.
- The Spanish invoice footer now reads "Factura" instead of "Fatura."

**Other**
- Ledgerly now runs on a newer database version, with no changes to how you use it.
