Ledgerly update

**Action required**
- If you use two-factor authentication, you can now set it up under Settings → Security using an authenticator app.

**What's new**
- Your CSV exports now include a Paid on column.

**Fixes**
- Autosave no longer loses edits when you have Ledgerly open in two tabs.
- The Spanish invoice footer now reads "Factura" instead of "Fatura."

**Other improvements**
- Faster, more reliable data storage behind the scenes.
- Tax calculations are now more thoroughly tested, so they're more reliable.
