# What's new in Ledgerly

- **Freelancers: no action needed.** The changes below are live.
- **Faster API for integrations:** the public API now allows 300 requests per minute, up from 60.
- **Receipts from iPhone:** HEIC photos from iPhones can now be attached to expenses.
- **Profit & loss by client:** filter your profit & loss report by client.
- **Invoice list fix:** the 51st invoice in long lists now appears when you page through them.
- **Cleaner onboarding:** we removed leftover settings from the old onboarding flow.
- **Faster, more reliable image storage:** images such as receipts and logos are now stored on a new provider. Your existing files are unchanged.
