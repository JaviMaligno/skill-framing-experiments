**Ledgerly release notes**

**Action required**

- By 2026-11-15, API keys without an expiry date will be revoked. New keys expire after 90 days, so check your existing keys and replace any you still need before that date.

**Improvements**

- Clients page loads much faster for accounts with more than 500 clients.
- Checkout now records more detail to help us diagnose problems faster.

**Fixes**

- The tooltip on the Due date column no longer overlaps the Status filter.
