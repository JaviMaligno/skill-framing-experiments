# Ledgerly release notes

**Action required**
- If you upload receipts or use the Public API, no action is needed; changes below take effect automatically.

**What's new**
- Profit & loss reports can now be filtered by client.
- Public API rate limit raised from 60 to 300 requests per minute.

**Fixes**
- Expense receipts photographed on iPhone (HEIC) now upload correctly.
- The 51st invoice no longer goes missing from invoice lists.

**Other improvements**
- Images are now stored on a faster, more reliable service.
- Cleaned up old onboarding settings.
