# What's new in Ledgerly

- **Action needed by November 15, 2026:** API keys now expire 90 days after they're created. Existing API keys with no expiry date will be revoked on November 15, 2026. Create a new key before then and update any integration that uses the old one.
- The Clients page loads much faster for accounts with more than 500 clients. It could previously take about 8 seconds.
- The tooltip on the Due date column no longer covers the Status filter.
