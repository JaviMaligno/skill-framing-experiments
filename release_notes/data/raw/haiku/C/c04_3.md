**Ledgerly release notes**

**Action required before 2026-12-01**
- The XLS export format is being removed on 2026-12-01. If you export to XLS, switch to XLSX or CSV before then.

**Improvements**
- Recurring invoices can now be set to bill on the last day of the month.
- Tracing has been added to improve how we diagnose issues.

**Fixes**
- "Send reminder" no longer sends two emails when clicked twice.
- Logo uploads now work for SVG files larger than 1 MB.
