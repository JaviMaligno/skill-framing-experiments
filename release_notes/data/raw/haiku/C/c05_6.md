## What's new in Ledgerly

- **SEPA Direct Debit payments:** Accept SEPA Direct Debit through GoCardless. Set it up in Settings > Payments.
- **Fresher converted totals:** Exchange rates now refresh every hour instead of once a day, so converted totals are more up to date.
- **Send button fix:** Send now works for clients without an email address.
- **Date picker fix:** Weeks now start on Monday for UK users, not Sunday.
