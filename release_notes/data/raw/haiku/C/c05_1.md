## What's new

- **SEPA Direct Debit payments:** Accept SEPA Direct Debit payments through GoCardless. Set it up in Settings > Payments.
- **Fresher converted totals:** Currency conversions now update every hour instead of once a day.
- **Send button fix:** The Send button no longer fails for clients who have no email address.
- **Date picker fix:** Weeks now start on Monday for UK users, as expected.
