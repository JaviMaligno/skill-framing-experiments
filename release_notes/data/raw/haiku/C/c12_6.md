# Ledgerly update

- **Multi-currency invoicing:** Invoice in one currency and get paid in another. The conversion is shown on the PDF.
- **Clients can be archived:** Archive clients you no longer work with instead of deleting them. Archived clients are hidden from your lists.
- **CSV import fixed:** Files with semicolons as separators (common in Spain and Germany) now import correctly.
- **Email preview fixed:** The preview now shows the client's name instead of a `{{client_name}}` placeholder.
- **Faster, lighter app:** Pages load faster and use less data.
