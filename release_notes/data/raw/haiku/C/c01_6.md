**Ledgerly release notes**

**Action required**

- API keys now expire after 90 days. Existing keys with no expiry will stop working on November 15, 2026. Create a new key in Settings before then and update any integrations that use the old one.

**What's new and improved**

- Clients page loads much faster for accounts with more than 500 clients.
- Checkout now records extra diagnostic details to help us resolve issues faster.

**Fixes**

- The tooltip on the Due date column no longer overlaps the Status filter.
- Faster load times and a more reliable experience across the app.
