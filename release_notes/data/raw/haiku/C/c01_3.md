## What's new in Ledgerly

- **Action required by November 15, 2026:** API keys now expire 90 days after they're created. Any existing key without an expiry date will stop working on November 15, 2026. Create a new key and update your integrations before then.
- The Clients page loads much faster for accounts with more than 500 clients. It previously took up to 8 seconds.
- Fixed a tooltip on the Due date column that covered the Status filter.
