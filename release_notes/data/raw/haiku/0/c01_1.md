# Ledgerly Release Notes

**New**
- **API keys now expire after 90 days.** Existing keys without an expiry date will be revoked on **November 15, 2026**. Check your keys and plan rotation before then. (FAC-1182, #4410)

**Improvements**
- **Faster Clients page.** Fixed a slow query that made the Clients page take up to 8 seconds to load for accounts with more than 500 clients.
- **Checkout diagnostics.** Added Sentry breadcrumbs to the checkout flow to make payment issues easier to trace.

**Fixes**
- Fixed a tooltip on the Due date column that overlapped the Status filter.

**Under the hood**
- Refactored InvoiceRenderer to use pdfkit 0.15.
- Upgraded eslint to 9.12.
