**Ledgerly v2026.10.19 Release Notes**

**New Features**
- **Zapier:** New trigger, "Invoice overdue," so you can automate follow-ups and notifications when an invoice passes its due date.
- **Payment QR codes on invoices:** Invoices now include an EPC QR code (Girocode), so clients can scan it to pay straight from their banking app.

**Improvements**
- **Onboarding test coverage:** Added end-to-end Playwright tests for the onboarding flow to help catch regressions earlier.
- **Codebase modernization:** Remaining class components have been converted to hooks.

**Bug Fixes**
- **Large invoice generation:** Fixed a memory leak in the PDF worker that caused generation to time out on invoices with 100+ line items.
- **Duplicate invoice due date:** The "Duplicate invoice" button no longer copies the original due date.
