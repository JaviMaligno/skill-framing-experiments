Ledgerly release notes for this week:

**New & improved**
- **Higher public API rate limit:** The public API limit has increased from 60 to 300 requests per minute (LED-120).
- **Profit & loss by client:** Profit & loss reports can now be filtered by client.
- **Faster, more reliable image storage:** Image storage has moved from S3 to Cloudflare R2.
- **Cleaner onboarding:** Old onboarding feature flags have been removed.

**Bug fixes**
- **iPhone photo receipts:** Expense receipts in HEIC format (the default for iPhone photos) can now be uploaded.
- **Invoice pagination:** Fixed an off-by-one error that could hide the 51st invoice in lists.
