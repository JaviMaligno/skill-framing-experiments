## Ledgerly release notes: week of October 19, 2026

**New and improved**
- **Higher Public API rate limit:** The limit has increased from 60 to 300 requests per minute. (LED-120)
- **Profit & loss filtered by client:** You can now filter the profit & loss report by client.
- **Faster, more reliable file storage:** Image storage has moved from S3 to Cloudflare R2. You shouldn't notice a change in how images load or upload.
- **Simpler onboarding:** We removed feature flags for the old onboarding flow.

**Fixes**
- **HEIC receipts now upload:** Expense receipts in HEIC format, such as iPhone photos, can be uploaded again.
- **All invoices appear in lists:** A pagination bug hid the 51st invoice in lists. All invoices now show up.
