**Ledgerly release notes: week of October 19, 2026**

**New features**
- **Multi-currency invoicing:** Invoice in one currency and get paid in another. The conversion is now shown on the invoice PDF.
- **Batch client resolver:** The GraphQL client resolver now batches requests with DataLoader, reducing redundant queries.
- **Archive clients:** Clients can be archived instead of deleted. Archived clients are hidden from lists.

**Fixes**
- **CSV import:** Files with semicolon delimiters, common in Spain and Germany, now import correctly.
- **Email preview:** The preview no longer shows a raw `{{client_name}}` placeholder.

**Performance**
- **Smaller stylesheet:** Removed unused CSS, reducing its size by 40 KB.
