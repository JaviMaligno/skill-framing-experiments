# Ledgerly Release Notes

## New Features & Improvements

- **API key expiration:** API keys now expire after 90 days. Existing keys without an expiry date will be revoked on **November 15, 2026**, so please create new keys before then if you rely on any existing ones. (#4410, FAC-1182)
- **Sentry breadcrumbs in checkout:** Added breadcrumbs to the checkout flow to make errors easier to trace and debug.

## Performance

- **Faster Clients page:** Fixed an N+1 query that caused the Clients page to take up to 8 seconds to load for accounts with more than 500 clients.

## Bug Fixes

- **Due date tooltip:** Fixed a tooltip on the Due date column that overlapped the Status filter.

## Internal / Maintenance

- Refactored `InvoiceRenderer` to use pdfkit 0.15.
- Upgraded eslint to 9.12.
