# Ledgerly Release Notes

## Deprecations
- **Legacy XLS export is deprecated and will be removed on 2026-12-01.** Switch to XLSX or CSV export before then.

## New Features
- **Recurring invoices can now bill on the last day of the month.** Choose this option when setting up a recurring schedule.
- **API gateway tracing with OpenTelemetry.** Requests through the API gateway are now traced, which gives better visibility into performance and debugging.

## Improvements
- **EmailService extracted into its own module.** This is an internal refactor with no change to behavior.

## Bug Fixes
- **Duplicate reminder emails fixed.** Clicking "Send reminder" twice no longer sends two emails; a debounce now prevents the second send.
- **SVG logo uploads fixed.** SVG files larger than 1 MB now upload successfully.
