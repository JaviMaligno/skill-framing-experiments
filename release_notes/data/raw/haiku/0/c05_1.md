## Ledgerly Release Notes (October 19, 2026)

### New features

- **SEPA Direct Debit payments via GoCardless:** Accept SEPA Direct Debit payments from European clients. Set it up under **Settings → Payments**.

### Improvements

- **Fresher converted totals:** Exchange rates now refresh every hour instead of every 24 hours, so totals in other currencies reflect recent rate changes.

### Bug fixes

- **Send button crash:** Fixed a null pointer error that crashed the Send button when a client had no email address on file.
- **Date picker for UK users:** The date picker now starts weeks on Monday instead of Sunday.

### Under the hood

- Renamed the database column `amount_cents` to `amount_minor`.
- Added Storybook stories for the Button component.
