# Ledgerly Release Notes

## New Features
- **Two-factor authentication:** Secure your account with TOTP-based 2FA. Enable it under **Settings → Security**.
- **CSV export improvement:** Exports now include the **Paid on** column.

## Improvements
- **Test coverage:** Unit test coverage for the tax module increased to 85%.
- **Database upgrade:** Sessions have been migrated to Postgres 16.

## Bug Fixes
- **Autosave race condition:** Fixed an issue where edits could be lost when autosave ran with two tabs open.
- **Spanish invoice footer:** Corrected a typo, "Fatura" is now "Factura."
