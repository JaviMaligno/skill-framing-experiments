Ledgerly release notes: this week's update

**New**
- **Webhooks:** Added the `invoice.paid` event (LED-77), so you can get notified when an invoice is paid.
- **Dark mode for the dashboard:** Turn it on in Settings → Appearance.

**Improvements**
- **Stripe webhook retries:** Retry attempts for failed Stripe webhook deliveries are now logged, making failed deliveries easier to trace.
- **Faster, lighter date handling:** We replaced moment.js with date-fns.

**Fixes**
- **PDF totals in de-DE:** Invoice PDFs no longer round totals to whole euros when the locale is de-DE.

**Internal**
- **CI:** Build runners have been upgraded to ubuntu-24.04.
