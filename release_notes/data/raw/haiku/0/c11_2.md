# Ledgerly 2.x Release Notes

## Security

- **Stronger passwords:** The minimum password length is now 12 characters. If your current password is shorter, you'll be asked to change it at your next sign-in after November 20, 2026.
- **Improved password hashing:** Passwords are now hashed with argon2id instead of bcrypt.
- **Sign in with Microsoft:** You can now sign in to Ledgerly with your Microsoft account using OAuth.

## Fixes

- **Session expiry no longer loses your work:** Your session no longer expires silently while you're editing. Unsaved invoice drafts are preserved.
- **German Settings page:** The German translation now displays correctly on the Settings page.

## Improvements

- **TypeScript 5.7:** Ledgerly now builds with TypeScript 5.7.
