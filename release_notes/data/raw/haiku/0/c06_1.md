# Ledgerly Release Notes

**Highlights**

- **Single sign-on with Google Workspace (beta):** Team accounts can now sign in with Google Workspace SSO. This is in beta, so please share feedback with us as you try it.

**Improvements**

- Upgraded the app from React 18 to React 19.
- Added rate limiting to public invoice links to protect against abuse.

**Bug fixes**

- VAT number validation no longer rejects valid Irish numbers in the IE1234567FA format.
- The dashboard chart no longer shows last month's revenue as current after midnight UTC.
- Fixed a flaky deploy pipeline on staging.
