Ledgerly release notes

**New integrations**
- **Zapier: "Invoice overdue" trigger.** Zaps can now start automatically when an invoice passes its due date, so you can send reminders, notify your team, or log the event in another tool.

**New features**
- **Payment QR codes on invoices.** Invoices now include an EPC QR code (Girocode), so clients can scan it with their banking app to pay the exact amount.

**Bug fixes**
- **Large invoice PDFs no longer time out.** A memory leak in the PDF worker caused generation to fail for invoices with 100+ line items. Those invoices now generate reliably.
- **Duplicate invoice keeps the correct due date.** The "Duplicate invoice" button was copying the original's due date. The copy now gets a fresh due date.

**Improvements**
- **Faster, more consistent UI code.** The remaining class components have been converted to hooks.
- **Onboarding test coverage.** New end-to-end Playwright tests cover the onboarding flow.
