# Ledgerly Release Notes

## New
- **E-invoicing via Peppol:** Send invoices over the Peppol network to public-sector clients.

## Fixes
- **Credit notes:** Credit notes now correctly subtract from the client's outstanding balance.
- **Mobile Safari:** The "Mark as paid" button is no longer disabled on mobile Safari.

## Improvements
- **Structured logging:** The invoice sender now emits structured logs, making issues easier to diagnose.
- **Tax engine rewrite:** The tax engine has been rewritten in Rust. There is no change in behaviour.
- **Infrastructure:** Terraform modules have been updated.
