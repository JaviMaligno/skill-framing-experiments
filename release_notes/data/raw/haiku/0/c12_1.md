# Ledgerly Release Notes

## New
- **Multi-currency invoicing:** Invoice a client in one currency and get paid in another. The conversion is shown on the invoice PDF.
- **Archive clients:** Archive a client instead of deleting it. Archived clients are hidden from your client lists.

## Improvements
- **Faster client data loading:** The GraphQL client resolver now batches requests with DataLoader.
- **Smaller app footprint:** Removed unused CSS, reducing the stylesheet by about 40 KB.

## Fixes
- **CSV import with semicolon delimiters:** Files that use semicolons as separators (common in Spain and Germany) now import correctly.
- **Email preview placeholder:** The email preview now fills in the client's name instead of showing a raw `{{client_name}}` placeholder.
