**Ledgerly Release Notes: Week of October 19, 2026**

**New Features**
- **Two-factor authentication:** You can now enable TOTP-based two-factor authentication under **Settings → Security**.
- **CSV export includes Paid on:** Exported CSVs now contain the *Paid on* column.

**Fixes**
- **Autosave race condition:** Fixed an issue where edits could be lost when autosave ran in two open tabs at the same time.
- **Spanish invoice footer:** Corrected the typo "Fatura" to "Factura" in the Spanish invoice footer.

**Improvements**
- **Database upgrade:** The sessions table has been migrated to PostgreSQL 16.
- **Test coverage:** Unit test coverage for the tax module increased to 85%.
