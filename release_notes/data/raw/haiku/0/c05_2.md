## Ledgerly release notes

**New features**
- **SEPA Direct Debit via GoCardless:** Accept SEPA Direct Debit payments. Enable it under Settings → Payments.

**Improvements**
- **Fresher converted totals:** Exchange rates now refresh every hour instead of every 24 hours, so totals in other currencies reflect more recent rates.

**Bug fixes**
- **Send button crash:** Fixed a crash when a client had no email address on file.
- **Date picker for UK users:** Weeks now start on Monday instead of Sunday.

**Internal**
- The database column `amount_cents` has been renamed to `amount_minor`.
- Added Storybook stories for the Button component.
