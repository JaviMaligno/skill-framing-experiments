# Ledgerly release notes

- **Action needed:** Team accounts can now sign in with Google Workspace (beta). Let us know if you'd like to try it.
- Fixed a problem where valid Irish VAT numbers (IE1234567FA format) were rejected.
- Fixed a problem where the dashboard showed last month's revenue as current after midnight UTC.
- Fixed a problem where public invoice links could be opened too many times in a short period. Links now have a limit on how often they can be used.
- Small fixes and improvements to Ledgerly's reliability and performance.
