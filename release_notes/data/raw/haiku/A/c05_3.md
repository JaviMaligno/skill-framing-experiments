# Ledgerly release notes

- **Action may be needed:** To keep receiving payments, check that your SEPA Direct Debit setup is connected under Settings → Payments. You can now accept SEPA Direct Debit payments through GoCardless from the same screen.
- Fixed a crash that happened when you tried to send an invoice to a client who had no email address saved. The Send button now works.
- Converted totals in multi-currency views now update every hour instead of once a day, so they reflect current exchange rates.
- Fixed the date picker so weeks start on Monday for UK users, as expected.
