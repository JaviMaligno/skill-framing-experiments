# Release notes

- **Action needed by November 15, 2026:** API keys without an expiry date will be revoked on that date. New API keys now expire after 90 days, so create a new key before then and update any integrations that use the old one.
- Clients page loads much faster for accounts with more than 500 clients.
- Fixed a tooltip on the Due date column that could overlap the Status filter.
- Small under-the-hood improvements to invoice PDF creation and the checkout flow.
