# Ledgerly: what's new this week

- **Invoice in one currency, get paid in another.** The conversion is shown on the PDF.
- **Fixed:** Importing a CSV file with semicolons between values now works, as it does for files common in Spain and Germany.
- **Fixed:** Email previews now show the client's actual name instead of a `{{client_name}}` placeholder.
- **Archive clients instead of deleting them.** Archived clients are hidden from your lists, and their records are kept.
- **Faster loading in several places** and a lighter app overall.
