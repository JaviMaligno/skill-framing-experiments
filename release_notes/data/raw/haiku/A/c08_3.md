# Ledgerly release notes

- **Action needed for Zapier users:** The Zapier integration has a new trigger, "Invoice overdue", so you can start a Zap when an invoice passes its due date.
- Payment QR codes (EPC QR / Girocode) now appear on invoices, so clients can pay by scanning the code with their banking app.
- Fixed a problem where very large invoices (100+ lines) took too long to generate or failed to download as PDF.
- Fixed "Duplicate invoice" copying the old due date. The duplicate now starts with a due date you can set.
- Smaller fixes and improvements to the app's stability and speed.
