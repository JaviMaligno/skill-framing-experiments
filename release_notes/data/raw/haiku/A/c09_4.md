# Ledgerly update

- **Action needed:** none for most users. If you upload expense receipts from an iPhone, you can now attach them without converting the photo first.
- Public API: the request limit is now 300 requests per minute, up from 60.
- Profit & loss reports can now be filtered by client.
- Fixed a bug where the 51st invoice was missing from invoice lists.
- Fixed a bug where iPhone photos in HEIC format could not be attached to expense receipts.
- Faster, more reliable image loading across Ledgerly. Images are now served from new storage.
- Cleaned up the old onboarding settings, so the setup flow is simpler to use.
