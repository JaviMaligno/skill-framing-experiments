# Ledgerly release notes

- **Action required:** Legacy XLS export will be removed on 2026-12-01. Switch to XLSX or CSV before then. Your existing XLS exports are not affected.
- Fixed an issue where clicking "Send reminder" twice sent two emails. Each reminder now sends once.
- Fixed an issue where logo uploads failed for SVG files larger than 1 MB. These uploads now go through.
- Recurring invoices can now be set to bill on the last day of the month.
