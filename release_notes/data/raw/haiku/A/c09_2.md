# What's new in Ledgerly

- **Lower API limits:** The Public API now allows 300 requests per minute, up from 60, so your integrations can make more calls before being throttled.
- **Expense receipts from iPhone:** You can now upload receipt photos taken on an iPhone, which previously failed.
- **Profit & loss by client:** Filter your profit & loss report by client to see how each one contributes to your results.
- **Invoice list:** Fixed an issue where the 51st invoice in a list was missing from view.
- **Faster onboarding:** The onboarding experience has been streamlined.
- **Faster image loading:** Images load from a new storage system.
