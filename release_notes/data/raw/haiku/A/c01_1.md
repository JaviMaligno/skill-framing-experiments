## Ledgerly release notes: October 19, 2026

- **Action required:** API keys now expire after 90 days. Existing API keys with no expiry date will be revoked on November 15, 2026. Create a new API key and update any integrations that use your current one before that date.
- The Clients page loads much faster for accounts with more than 500 clients. It previously could take about 8 seconds.
- Fixed a tooltip on the Due date column that overlapped the Status filter.
