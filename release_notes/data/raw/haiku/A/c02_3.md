# What's new in Ledgerly

- **Two-factor authentication is here.** You can now turn on two-factor authentication (TOTP) under Settings → Security to better protect your account.
- **Your CSV exports now include the Paid on date.** Check when each invoice was paid without any extra steps.
- **Edits no longer disappear when you have two tabs open.** Fixed an issue where text you typed could be lost while Ledgerly was open in more than one tab.
- **Spanish invoice footers now read "Factura."** Fixed a spelling error that showed "Fatura" on Spanish invoices.
- **Faster, more reliable app behind the scenes.** Also includes improved tax calculation checks.
