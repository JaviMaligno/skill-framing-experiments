# Ledgerly release notes

**Action required: API keys now expire after 90 days.** If you use an API key, check whether it was created before this release. Keys with no expiry date will be revoked on **November 15, 2026**, so create a new key in Settings before then and update any integrations that use the old one.

- Clients page loads much faster for accounts with more than 500 clients.
- Fixed a tooltip on the Due date column that overlapped the Status filter.
