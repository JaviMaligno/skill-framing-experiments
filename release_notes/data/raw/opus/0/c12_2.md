# Ledgerly Release Notes

## New

**Multi-currency invoicing**
You can now issue an invoice in one currency and get paid in another. The PDF shows the conversion, so your client sees both amounts.

**Archive clients**
You can now archive clients instead of deleting them. Archived clients are hidden from your client lists, and their records stay intact.

## Fixes

- **CSV import with semicolon delimiters:** CSV files that use semicolons as separators now import correctly. Many spreadsheet apps in Spain, Germany and other regions save files this way.
- **Email preview placeholder:** The email preview now shows your client's name instead of the raw `{{client_name}}` placeholder.
