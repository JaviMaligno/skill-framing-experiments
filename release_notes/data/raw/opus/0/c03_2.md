# Ledgerly Release Notes — Week of October 19, 2026

## New

- **Dark mode for the dashboard.** You can now switch the dashboard to a dark theme. Turn it on in **Settings → Appearance**.
- **New `invoice.paid` webhook event.** Ledgerly now sends an `invoice.paid` event when an invoice is marked as paid. Subscribe to it from your webhook settings to trigger your own workflows, such as updating your accounting system or sending a thank-you email. (LED-77)

## Fixes

- **Correct totals on PDF invoices in German (de-DE).** PDF invoices generated with the de-DE locale showed totals rounded to whole euros. They now show the exact amount, including cents. Invoices created from now on use the correct format.

## Improvements

- **Better tracking of Stripe webhook retries.** When a Stripe webhook delivery fails and is retried, each retry attempt is now logged. This makes it easier to diagnose payment sync problems.
- **Behind-the-scenes maintenance.** We updated the date-handling library (moment.js → date-fns) and our build infrastructure. You don't need to do anything.
