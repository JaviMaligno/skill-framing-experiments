# Ledgerly Release Notes: Week of October 19, 2026

## ⚠️ Action required: API key expiration

API keys now expire 90 days after they're created. **Existing API keys that have no expiration date will be revoked on November 15, 2026.** Any integration still using one of those keys will stop working on that date.

**What to do:** Before November 15, create new API keys and update your integrations to use them. Then plan to rotate your keys every 90 days.

## Improvements

- **Faster Clients page:** The Clients page loads much faster for accounts with many clients. Before this fix, accounts with more than 500 clients could wait up to 8 seconds for the page to load.

## Bug fixes

- The tooltip on the **Due date** column no longer covers the **Status** filter.
