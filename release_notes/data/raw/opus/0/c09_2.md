# Ledgerly Release Notes

## New

**Filter Profit & Loss reports by client**
You can now filter the Profit & Loss report by client to see how much each customer earns you and what it costs to serve them.

## Improvements

**Higher Public API rate limit**
The Public API now accepts up to 300 requests per minute, up from 60. Integrations and bulk syncs can run faster without hitting the limit.

## Fixes

**iPhone photos now upload as expense receipts**
Receipts in HEIC format, the default photo format on iPhones, failed to upload. They now upload correctly.

**All invoices now show in paginated lists**
A pagination bug kept the 51st invoice from appearing in invoice lists. Every invoice now shows up.
