# Ledgerly Release Notes

## New

**E-invoicing over Peppol**
You can now send invoices to public-sector clients through the Peppol network, straight from Ledgerly.

## Fixes

- **Credit notes now reduce outstanding balances.** Issuing a credit note now subtracts the amount from the client's outstanding balance as expected.
- **"Mark as paid" works on mobile Safari.** The button was disabled on mobile Safari and can now be used normally.
