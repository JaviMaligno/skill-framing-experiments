# Ledgerly Release Notes

## New
- **Two-factor authentication (2FA):** You can now protect your account with an authenticator app (TOTP). Turn it on under **Settings → Security**.

## Improvements
- **CSV export now includes "Paid on":** Exported CSV files have a new **Paid on** column, so you can see when each invoice was paid.

## Fixes
- **Autosave no longer loses edits with multiple tabs open:** Fixed a problem where changes could be lost if you edited in two browser tabs at the same time.
- **Spanish invoice footer typo:** The footer on Spanish invoices now correctly reads "Factura" (it previously said "Fatura").
