# Ledgerly release notes: week of October 19, 2026

## ⚠️ Action required: API key expiration

API keys now expire 90 days after they are created.

**Existing keys that have no expiration date will be revoked on November 15, 2026.** If your integrations use one of these keys, create a new key and update your integrations before that date so they keep working.

## Improvements

- **Faster Clients page:** The Clients page now loads much faster for large accounts. Before this fix, accounts with more than 500 clients could wait about 8 seconds for it to load.

## Bug fixes

- The tooltip on the **Due date** column no longer covers the **Status** filter.
