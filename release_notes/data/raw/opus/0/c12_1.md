# Ledgerly Release Notes

## New

**Multi-currency invoicing.** You can now issue an invoice in one currency and get paid in another. The invoice PDF shows the currency conversion, so your client can see exactly what they're paying.

**Archive clients.** You can now archive a client instead of deleting them. Archived clients no longer appear in your client lists, but their history stays intact.

## Fixes

- **CSV import with semicolons:** CSV files that use semicolons as delimiters now import correctly. This format is common in Spain, Germany and other regions.
- **Email preview placeholder:** Email previews now show the client's actual name. Before, they showed the raw `{{client_name}}` placeholder.
