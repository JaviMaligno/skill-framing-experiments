# Ledgerly Release Notes: Week of October 19, 2026

## New
- **Filter Profit & Loss reports by client.** You can now filter your P&L report by client to see how profitable each customer relationship is.

## Improved
- **Higher Public API rate limit.** The limit is now 300 requests per minute, up from 60, so integrations and automations can sync more data with fewer interruptions.

## Fixed
- **HEIC receipts now upload.** You can upload iPhone photos (HEIC format) as expense receipts without converting them first.
- **All invoices show up in paginated lists.** A pagination bug hid the 51st invoice in your list. Every invoice now appears.
