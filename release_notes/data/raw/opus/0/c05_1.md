# Ledgerly Release Notes

## New

**Accept SEPA Direct Debit payments.** You can now collect SEPA Direct Debit payments from clients through GoCardless. To set it up, go to **Settings → Payments**.

## Improvements

**Fresher currency conversions.** Exchange rates now refresh every hour instead of once a day, so converted totals stay closer to current rates.

## Fixes

- **Sending invoices to clients without an email address.** Clicking **Send** for a client with no email address on file used to crash. It now works as expected.
- **Calendar week start for UK users.** The date picker now starts the week on Monday for UK users instead of Sunday.
