# Ledgerly Release Notes: Week of October 19, 2026

## New
- **SEPA Direct Debit payments.** Your clients can now pay invoices by SEPA Direct Debit through GoCardless. To set it up, go to **Settings → Payments**.

## Improvements
- **Fresher currency conversions.** Exchange rates now update every hour instead of once a day, so converted totals are closer to current rates.

## Fixes
- Fixed a crash when pressing **Send** on an invoice for a client with no email address.
- UK users now see weeks starting on Monday in the date picker, instead of Sunday.
