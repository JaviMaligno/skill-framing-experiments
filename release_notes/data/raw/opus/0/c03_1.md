# Ledgerly Release Notes: Week of October 19, 2026

## New

- **Dark mode for the dashboard.** You can now switch the dashboard to a dark theme. Go to **Settings → Appearance** to turn it on.
- **New `invoice.paid` webhook event.** Ledgerly now sends an `invoice.paid` event when an invoice is paid. Subscribe to it in your webhook settings to start your own workflows when payment arrives, such as fulfilment, notifications or accounting syncs. (LED-77)

## Fixed

- **PDF invoice totals in the German (de-DE) locale.** PDF invoices generated with the de-DE locale showed totals rounded to whole euros. They now show exact amounts, including cents.

## Improved

- **Stripe webhook retries are now logged.** Ledgerly now records each retry when a Stripe webhook delivery fails, which makes delivery problems easier to investigate.

## Under the hood

- Replaced moment.js with date-fns for date handling. This makes the app lighter and uses a library that is still being maintained. You shouldn't notice any change in how dates are shown.
- Upgraded our CI build runners to Ubuntu 24.04.
