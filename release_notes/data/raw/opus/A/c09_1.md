**What's new in Ledgerly this week**

- **Filter profit & loss by client:** In Reports, you can now filter your profit & loss report by client to see how much each client brings in.
- **Higher Public API limit:** The Public API now allows up to 300 requests per minute, up from 60.
- **Fixes:** You can now upload expense receipts in HEIC format, which is the default for iPhone photos. Also, if you have more than 50 invoices, all of them now show in your invoice list. Before, one could be missing.
