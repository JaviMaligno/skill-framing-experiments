**Ledgerly update: API key changes and fixes**

- **Action required by November 15, 2026:** API keys created without an expiry date will stop working on November 15, 2026. Create a new API key before then and use it wherever you use your current one.
- New API keys now expire after 90 days. You'll need to replace each key before it expires.
- The Clients page now loads quickly, even if you have a lot of clients. Before, it could take several seconds.
- The Due date column tooltip no longer covers the Status filter.
