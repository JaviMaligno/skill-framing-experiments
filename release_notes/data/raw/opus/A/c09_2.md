**What's new in Ledgerly this week**

- **Profit & loss by client:** You can now filter the profit & loss report by client to see how much each client earns you.
- **Higher API limit:** If you connect other tools to the Ledgerly API, you can now send up to 300 requests per minute instead of 60.
- **Fixes:** You can now upload expense receipts in HEIC format, which is the default for iPhone photos. Long invoice lists no longer leave out an invoice when you move to the next page.
