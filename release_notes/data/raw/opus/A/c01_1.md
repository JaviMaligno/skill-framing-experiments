**Ledgerly update: API key changes and fixes**

- **Action required by November 15, 2026:** API keys now expire after 90 days. Any API key you created before this update has no expiry date and will stop working on November 15, 2026. Create a new API key before then and update any tools that use it.
- The Clients page now loads quickly for accounts with many clients. Before, it could take several seconds.
- The tooltip on the Due date column no longer covers the Status filter.
