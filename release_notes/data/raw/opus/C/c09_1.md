# What's new in Ledgerly

- **Profit & loss by client:** You can now filter your profit & loss report by client.
- **Higher Public API limit:** The Public API now accepts up to 300 requests per minute, up from 60.
- **Fixes:**
  - You can now upload expense receipts in HEIC format, the default photo format on iPhones.
  - If you had more than 50 invoices, one of them was missing from your invoice list. It now appears.
