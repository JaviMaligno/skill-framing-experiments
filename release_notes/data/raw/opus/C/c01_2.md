# What's new in Ledgerly

- **Action needed by November 15, 2026:** API keys created without an expiry date will stop working on November 15, 2026. To keep your connected tools working, create a new API key and replace the old one before then.
- API keys now expire 90 days after you create them.
- The Clients page now loads quickly for accounts with many clients. Before, it could take several seconds.
- The tooltip on the Due date column no longer covers the Status filter.
