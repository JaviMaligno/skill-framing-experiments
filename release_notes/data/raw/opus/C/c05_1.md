## What's new in Ledgerly

- **SEPA Direct Debit payments:** Clients can now pay you by SEPA Direct Debit through GoCardless. To set it up, go to **Settings → Payments**.
- **More up-to-date currency conversions:** Totals converted into another currency now use exchange rates from the last hour, not the last day.
- **Fixes:**
  - The **Send** button no longer stops working when a client has no email address.
  - The date picker now starts the week on Monday for UK users.
