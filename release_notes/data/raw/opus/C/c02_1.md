## What's new in Ledgerly

- **Two-factor authentication:** You can now protect your account with a code from an authenticator app. Turn it on in **Settings → Security**.
- **CSV export:** Exported files now include the **Paid on** column, so you can see when each invoice was paid.
- **Fixes:**
  - Edits are no longer lost when you have Ledgerly open in two tabs at once.
  - Spanish invoices now correctly say "Factura" in the footer.
