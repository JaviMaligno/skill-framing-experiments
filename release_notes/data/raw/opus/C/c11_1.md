# Ledgerly update

- **Action required by November 20, 2026:** Passwords must now be at least 12 characters long. If yours is shorter, change it before November 20, 2026. After that date, you'll be asked to set a new password the next time you sign in.
- You can now sign in with your Microsoft account.
- Fixes:
  - You were sometimes signed out without warning, and unsaved invoice drafts were lost. This no longer happens.
  - Some text on the Settings page didn't show in German. It's now translated.
