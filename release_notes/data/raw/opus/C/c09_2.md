# What's new in Ledgerly

- **Profit & loss by client:** You can now filter your profit & loss report by client.
- **Higher Public API limit:** If you connect other tools to Ledgerly through the Public API, you can now make up to 300 requests per minute instead of 60.
- **Fixes:**
  - You can now upload expense receipts in HEIC format, the format iPhones use for photos.
  - Your invoice list no longer skips an invoice when it moves to the next page.
