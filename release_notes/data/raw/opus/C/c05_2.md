## What's new in Ledgerly

- **SEPA Direct Debit payments:** clients can now pay you by SEPA Direct Debit through GoCardless. Set it up in **Settings → Payments**.
- **More up-to-date currency conversion:** exchange rates now refresh every hour, so converted totals are closer to current rates.
- **Fixes:**
  - The **Send** button no longer crashes when a client has no email address.
  - For UK users, the date picker now starts weeks on Monday.
