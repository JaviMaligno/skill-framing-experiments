# Ledgerly update

- **Action required by November 15, 2026:** API keys that don't have an expiry date will stop working on November 15, 2026. To avoid interruptions, create a new API key before then and replace your old one with it. From now on, all new API keys expire after 90 days.
- The Clients page now loads much faster. Before, it could take up to 8 seconds for accounts with more than 500 clients.
- The tooltip on the **Due date** column no longer covers the **Status** filter.
