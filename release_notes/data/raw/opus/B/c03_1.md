## What's new in Ledgerly

- **Dark mode is here.** Switch the dashboard to dark under **Settings → Appearance**.
- **Get notified when you're paid.** If you use webhooks, you can now subscribe to the new `invoice.paid` event. It fires as soon as a client pays an invoice.
- **Fixed: German PDF invoices now show cents.** If your invoices used German formatting, the totals on the PDF were rounded to whole euros. They now show the exact amount.
