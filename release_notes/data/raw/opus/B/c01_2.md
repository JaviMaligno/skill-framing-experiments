**Action needed by November 15, 2026:** If you connect Ledgerly to other tools with an API key, check your keys. Any key you made before this update has no expiry date, and on November 15, 2026 those keys will stop working. Create a new key before then and swap it into your integrations so nothing breaks. From now on, every API key expires 90 days after you create it.

## What's new this week

- **New API keys expire after 90 days.** Set a reminder to replace yours before it runs out.
- **The Clients page loads faster.** If you have more than 500 clients, it used to take about 8 seconds to open. Now it opens right away.

Also fixed: the tooltip on the Due date column no longer covers the Status filter.
