**Action needed by November 15, 2026:** API keys now expire after 90 days. Any key you made before this update that has no expiry date will stop working on **November 15, 2026**. If you use an API key to connect Ledgerly to other tools, create a new one before then and swap it in so nothing breaks.

## What's new

- **API keys now expire.** Every new key lasts 90 days, so you'll need to replace your keys from time to time.
- **The Clients page loads quickly again.** If you have hundreds of clients, the page could take up to 8 seconds to open. Now it opens right away.
- **No more tooltip covering the Status filter.** The tooltip on the Due date column used to sit on top of the Status filter, so you couldn't click it. That's fixed.
