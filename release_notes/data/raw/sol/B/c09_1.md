## What’s new in Ledgerly

- **Profit & loss by client:** Filter your report by client to see how each one contributes to your bottom line.
- **More room for API requests:** The Public API now allows 300 requests per minute, up from 60.
- **iPhone receipts welcome:** You can now upload expense receipts in HEIC format.
- **No more missing invoice:** The 51st invoice now appears as expected when you page through your invoices.
