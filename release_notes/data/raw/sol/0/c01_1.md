## Ledgerly release notes

### API key security
New API keys now expire after 90 days. **Existing keys without an expiry date will be revoked on November 15, 2026.** Replace these keys before that date to avoid interruptions to your integrations.

### Fixes and improvements
- Fixed a performance issue that caused the Clients page to take 8 seconds to load for accounts with more than 500 clients.
- Fixed the Due date tooltip overlapping the Status filter.
- Updated PDF rendering internals.
- Improved checkout diagnostics to help investigate issues.
