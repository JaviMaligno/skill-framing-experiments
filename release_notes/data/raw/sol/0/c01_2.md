## Ledgerly release notes

### Action required: API key expiration
API keys now expire after 90 days. Existing keys without an expiration date will be revoked on **November 15, 2026**. Replace those keys before that date to avoid interruptions to your integrations.

### Fixes
- Fixed a performance issue that caused the Clients page to take around 8 seconds to load for accounts with more than 500 clients.
- Fixed the Due date column tooltip overlapping the Status filter.
